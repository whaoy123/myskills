# 系统协议｜标签与任务正文

## 清单与层级

清单按领域划分；真实项目使用父任务。新工作层级为 project → phase → task；旧 block 仅历史兼容，不再创建。

## 周交付

沿用 week_start + weekly_commitment；weekly_delivery 是版本 1 JSON 扩展。当前合同只存在 owner 任务，支撑任务只引用、不重挂父级。本周验收不自动完成大任务。

## 状态标签

状态/进行中、状态/等待、状态/暂停互斥。未开始不加状态标签；完成使用滴答原生状态。不设置放弃状态。

## 进度

只使用 0、25、50、75、90、100。

## 正文

自然语言保存当前背景、完成标准、结论、链接、路径和未决项，尽量 300 字以内，最多约 500 字。用户要求只留概括时设置 privacy: summary_only。

正文底部只保留一个 Planner 机器区。评论用于历史，不作为当前状态。
