# 规划偏好｜作息与容量

## 可用时间

- 工作日：通常为 09:00/10:00–11:30、14:00–17:00、18:00/19:00–21:00。
- 08:45 有早间打卡。
- 午饭约 11:30–12:30，通常午休至 14:00。
- 周六主要上午可用，最晚到 15:00。
- 周日默认不安排工作，但可临时破例。
- 睡眠保护约 01:00–08:00。

## 精力与工作方式

- 下午精力通常最好。
- 偏好约 60 分钟专注块，休息 10–20 分钟。
- 连续脑力工作上限约 4–5 小时。
- 每天最多安排 3 个重要任务。
- 低精力时优先安排重复性或可与 AI 并行的工作。
- 尽量比硬截止提前 2–5 天完成。

## 健身与生活

- 晚饭通常在 17:00–19:00。
- 健身优先紧接晚饭前后，理想目标 120 分钟。
- 羽毛球每周至少一次，日期和时间可灵活。
