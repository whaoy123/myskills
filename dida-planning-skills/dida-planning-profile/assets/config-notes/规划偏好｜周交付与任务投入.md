# 规划偏好｜周交付与任务投入

- 核心周交付物默认上限：2。允许 0–1 个，不凑数；用户可按实际情况调整。
- 默认两个方向：工作/课题、求职/长期发展。不预设某个职业一定适合用户。
- 周投入预算：unknown；只用用户明确给出的预算，不读取日历容量。
- 必办节点：计入工作量和等待风险，即使不占核心名额。
- 验收合同：产物、范围、标准、方式、支撑任务、本周不做。
- 复用已有 task/phase，不新建周总结任务或执行块，不跨项目强行改父任务。
- 长期发展被挤占：说明原因、替换项与重新评估条件，不默默无限延期。
- 复盘：验收与部分进展同时保留；先归档，再重选，不自动滚动未完成项。
