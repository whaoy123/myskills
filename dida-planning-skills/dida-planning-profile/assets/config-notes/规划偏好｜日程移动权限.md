# 规划偏好｜日程移动权限

- fixed：会议、预约、出行和已开始任务；AI 不得移动。
- protected：可在同一天调整，但不得跨天、删除或缩短；健身默认属于此类。
- movable：普通任务可自动调整日期和时间。
- 重复任务单独设置移动等级，不因重复而自动固定。
- AI 不得自行改变硬截止。
- 个人日历占用不得重叠；并行 AI 时间可以重叠，但不得重复计算用户专注时间。
- 已开始任务当天放不下时，必须询问延长、拆块或改期。
- 当天未完成任务在下次规划时重新判断，不自动顺延。
- 收集箱只在用户明确要求时整理。
- 时区自动使用用户当前所在地。
