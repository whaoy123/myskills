# Capture examples

## Clear task

User: “把明天下午修改测试方案记录到项目与硬件，放到南航发电机下面。”

- Title: `修改直通测试方案`
- List: `项目与硬件`
- Parent: resolved `南航发电机`
- Date semantics: `execution_window`
- Mobility: `movable`

## Ambiguous idea

User: “记一下，以后可以研究特殊语音增强。”

- Put in inbox.
- Role: `task` or idea-like task; do not create a project hierarchy yet.
- No estimate or date.

## Summary-only

User: “这个客户项目只留一个概括。”

- Store only the action, completion criteria, and local document location.
- Set `privacy: summary_only`.
