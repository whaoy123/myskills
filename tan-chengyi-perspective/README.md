# 谭成义 · 电子健身教练 Skill

一个基于谭成义公开训练内容重建的 Codex Skill，用于安排训练计划、分析动作、处理平台期，并把训练、营养、睡眠和恢复组织成可复盘的反馈闭环。

> [!IMPORTANT]
> 本项目是基于公开资料的研究性重建，不是谭成义本人、官方产品或私教服务，也不代表其未公开观点。它不能替代医生、康复治疗师或注册营养师。

## 能做什么

- 根据目标、训练经历、器械、时间和恢复状态生成训练模板
- 按蹲—推—拉、三分化、全身或上下肢结构安排周计划
- 提供动作口令、热身、进退阶、RIR/RPE、休息与进阶规则
- 分析卧推、下拉、划船、深蹲等动作的常见执行问题
- 处理平台期：区分技术、训练剂量与恢复限制
- 用训练日志、体重、围度、睡眠和疲劳建立复盘闭环
- 在疼痛、疾病、药物与营养问题上执行明确的安全分流

## 三类证据标签

Skill 会主动区分建议的来源，避免把生成内容冒充本人处方：

- `公开计划` / `公开观点`：可由本人或合作方公开内容确认
- `框架推断`：根据公开框架和用户信息生成的新方案
- `科学边界`：来自运动科学、医疗与营养安全要求的限制

```bash

  ~/.codex/skills/tan-chengyi-perspective
```

安装后如未立即显示，请新建一个任务或重启 Codex。

## 使用示例

```text
使用 $tan-chengyi-perspective，根据我的目标、训练经历和恢复状态，安排一套四周训练计划。
```

```text
谭师，我每周只能训练三天，想优先增胸背，器械齐全，应该怎么排？
```

```text
用谭成义的方法分析：我的高位下拉总是小臂先酸，背部感觉很弱，下一组应该怎么调整？
```

```text
我卧推两个月没进步。请按谭式框架给我一周重置方案，并写清楚 RIR、热身和复测条件。
```

为了得到真正个性化的方案，建议同时提供：

- 目标与期限
- 年龄、身高、体重及近期变化
- 训练年限和主要动作工作重量
- 每周可训练天数、单次时长和器械条件
- 当前疼痛、既往伤病、疾病或用药情况
- 最近两周的睡眠、压力、食欲和训练表现

## 安全边界

出现急性外伤、明显肿胀或关节不稳，持续加重或夜间疼痛，麻木、放射痛、突然无力，胸痛、异常呼吸困难或晕厥时，Skill 会停止为诱发症状的动作加负荷，并建议及时寻求专业评估。

本项目不提供：

- 医学诊断或伤病康复处方
- 处方药、激素或兴奋剂周期与剂量
- 针对疾病、孕期、未成年人或进食障碍风险的营养处方
- 谭成义未公开的课程、私教资料或所谓“内部知识”
