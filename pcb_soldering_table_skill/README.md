# PCB 焊接清单 Skill

把整个文件夹作为一个自定义 Skill 使用，核心规则见 `SKILL.md`。

## 推荐输入

一次任务优先给齐 5 类资料：

1. 网表（Altium `.NET` 或等价格式）
2. 原理图（PDF）
3. BOM（xlsx/xls/csv）
4. 采购表 / 下单表（xlsx/xls/csv/pdf）
5. 发票（PDF）

Skill 会先把原始资料交叉核对并标准化，再由 Python 生成最终焊接清单。

## 最终输出

默认只向用户交付：

- `soldering_table.xlsx`

清单固定包含：

- 位号
- 型号/规格
- 封装/类型
- 数量
- 贴片焊点
- 直插焊点
- 备注
- 补购状态

若采购数量覆盖需求，`补购状态` 留空；有缺口时写 `待补购 N只` 并高亮。

相同的最终实际型号会自动合并为同一行，例如原型号不同但最终都换成 `RVT1H1R0M0405` 时，会按同一实际物料合并。

## 推荐触发语

- “根据网表、原理图、BOM、采购表和发票做最终焊接清单”
- “按之前那个焊接清单格式，把替换型号和缺件也一起核对”
- “统计焊点并标出还需要补购哪些器件”
- “把采购表和发票与 BOM 对齐后生成焊接表”
