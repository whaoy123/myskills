# GB/T 7714—2015 参考文献生成器

## 目标

根据用户提供的 DOI、URL、论文题名、题录信息或 PDF，生成符合 GB/T 7714—2015 的参考文献。

生成和事实核验分开处理：格式可以依据现有字段生成，但作者、题名、年卷期、页码、文章编号、出版地、出版者、报告号、标准号、专利号、URL 和 DOI 等事实字段不得凭猜测补齐。

开始前阅读：

- `references/gbt7714-2015-quick-reference.md`

## 接受的输入

- 一个或多个 DOI；
- 出版者、期刊、会议、大学、政府机构或标准组织页面；
- 论文、报告、学位论文、标准或其他正式 PDF；
- 用户粘贴的题名、作者、年份等不完整题录；
- 已有参考文献，需要核实后重新生成；
- 学校、期刊或项目给出的特殊格式模板。

## 默认策略

能从上下文确定时直接执行，不重复询问。确有歧义且会改变最终结果时，最多询问一个关键问题。

### 编号

- 默认采用顺序编码制 `[1]`、`[2]`……
- 用户已有编号时保留原编号，除非用户要求重排。
- 若用户明确要求著者-出版年制，则按该体系组织，不混用两种标注体系。

### 载体

默认采用 `publication-first`：

- 已有正式年、卷、期、页码或文章编号的期刊论文，优先按正式出版物著录为 `[J]`；
- 仅因文献从网页下载，不改变其原有文献类型；
- 用户要求保留在线获取信息，或资源本身以联机网络形式发表时，使用 `/OL` 并著录引用日期与获取和访问路径；
- 网页、机构页面、在线公告等独立电子资源按 `[EB/OL]` 等实际类型著录。

### DOI

- DOI 只从文献首页、正式出版页面、DOI 落地页或权威题录服务获取；
- 使用在线形式著录时，如正式来源给出 DOI，可在获取和访问路径后如实著录；
- 不因搜索结果疑似匹配而补 DOI；
- URL 已经是 DOI 入口时，避免机械重复同一信息，除非用户模板要求同时保留。

## 证据优先级

### 有 PDF 时

优先查看：

1. 论文首页、题名页、版权页；
2. 页眉、页脚和末页；
3. DOI、报告号、标准号、专利号所在位置；
4. 会议录封面、目录或出版信息页。

PDF 文件名和 PDF 元数据只能作线索，不能替代页面证据。

### 需要联网时

按以下优先级核实：

1. 文献正式首页、正式 PDF、题名页或版权页；
2. 出版者、期刊、会议、大学、政府机构、标准组织正式页面；
3. DOI 正式落地页；
4. Crossref、PubMed、国家期刊平台、图书馆目录等权威题录服务；
5. 普通聚合网站只作检索线索。

不得把搜索摘要、AI 摘要或二次转载作为唯一题录依据。

## 执行流程

### 第一步：建立元数据记录

每条文献先建立内部记录：

```text
source_type:
carrier:
authors:
title:
other_title_info:
container_title:
year:
volume:
issue:
pages:
article_number:
place:
publisher:
conference_proceedings:
degree_institution_place:
degree_institution:
report_number:
standard_number:
patent_number:
published_or_updated_date:
cited_date:
url:
doi:
evidence:
unresolved_fields:
```

未知字段留空。

### 第二步：判定文献类型和载体

GB/T 7714—2015 常用文献类型代码：

- 专著 `M`
- 会议录 `C`
- 汇编 `G`
- 报纸 `N`
- 期刊 `J`
- 学位论文 `D`
- 报告 `R`
- 标准 `S`
- 专利 `P`
- 数据库 `DB`
- 计算机程序 `CP`
- 电子公告 `EB`
- 档案 `A`
- 舆图 `CM`
- 数据集 `DS`
- 其他 `Z`

常用电子载体代码：

- 磁带 `MT`
- 磁盘 `DK`
- 光盘 `CD`
- 联机网络 `OL`

组合形式如 `[J/OL]`、`[D/OL]`、`[R/OL]`、`[EB/OL]`。

判定原则：

- 期刊论文仍是期刊析出文献，不因在线下载改成 `[EB/OL]`；
- 会议录中的单篇论文按专著中的析出文献处理，通常使用 `[C]//`；
- 技术报告、白皮书、机构研究报告按其正式文献属性使用 `[R]` 或 `[R/OL]`；
- 学位论文使用 `[D]` 或 `[D/OL]`；
- 独立网页、电子公告或机构在线页面可使用 `[EB/OL]`；
- 无法归入已定义类型时才考虑 `Z`，不得用 `Z` 掩盖尚未完成的类型判断。

### 第三步：规范责任者

- 不超过 3 个同一著作方式的责任者：全部著录；
- 超过 3 个：著录前 3 个，中文后加“等”，西文后加 `et al.`；
- 个人著者采用姓在前、名在后的形式；
- 欧美著者的名可用缩写字母，缩写点省略；
- 西文姓氏按本标准示例使用全大写形式，如 `EINSTEIN A`；
- 用汉语拼音书写的人名，姓全大写；名可按每个汉字拼音首字母缩写，如 `LI J N`；
- 机构责任者按正式信息源著录，不自行翻译或缩写。

作者数量、顺序和机构层级必须依据原文或正式题录确认。

### 第四步：按类型套用结构

#### 专著

```text
[序号] 主要责任者. 题名: 其他题名信息[M]. 其他责任者. 版本项. 出版地: 出版者, 出版年: 引文页码.
```

第 1 版通常不著录版本项。引文页码按实际引用需要著录。

#### 专著中的析出文献 / 会议录中的论文

```text
[序号] 析出文献主要责任者. 析出文献题名[C]//专著主要责任者. 专著题名: 其他题名信息. 版本项. 出版地: 出版者, 出版年: 析出文献页码.
```

`//` 后著录会议录或论文集自身的正式题录信息。会议举办地、作者单位所在地和出版地不是同一字段，不得相互推断。

#### 期刊论文

```text
[序号] 主要责任者. 题名[J]. 期刊名, 年, 卷(期): 页码.
```

在线形式：

```text
[序号] 主要责任者. 题名[J/OL]. 期刊名, 年, 卷(期): 页码[引用日期]. 获取和访问路径. DOI.
```

无传统页码但正式出版物采用文章编号时，保留正式文章编号，不伪造页码范围。

#### 报纸文章

```text
[序号] 主要责任者. 题名[N]. 报纸名, 出版日期(版次).
```

联机报纸可使用 `[N/OL]`，并附引用日期和获取路径。

#### 学位论文

```text
[序号] 主要责任者. 题名[D]. 所在地: 学位授予单位, 年: 引文页码.
```

在线学位论文使用 `[D/OL]` 并补充引用日期和获取路径。

#### 报告

```text
[序号] 主要责任者. 题名: 报告号[R]. 出版地: 出版者, 出版年: 引文页码.
```

报告号有则按正式信息源著录。在线报告使用 `[R/OL]`。

#### 标准

标准作为专著类文献处理，常用结构：

```text
[序号] 主要责任者. 标准名称: 标准号[S]. 出版地: 出版者, 出版年: 引文页码.
```

不得把标准发布日期、实施日期、出版年机械混为同一字段。

#### 专利

```text
[序号] 专利申请者或所有者. 专利题名: 专利号[P]. 公告日期或公开日期.
```

在线专利可使用 `[P/OL]` 并补充引用日期和获取路径。

#### 独立电子资源

```text
[序号] 主要责任者. 题名: 其他题名信息[EB/OL]. 出版地: 出版者, 出版年: 引文页码(更新或修改日期)[引用日期]. 获取和访问路径. DOI.
```

实际字段不存在时不补造出版地、出版者、出版年或 DOI。资源有明确更新或修改日期时才著录该日期。

### 第五步：处理在线信息

- 联机网络资源必须使用与实际类型匹配的 `/OL`；
- 引用日期格式统一为 `YYYY-MM-DD`；
- URL 指向实际资源或正式落地页，避免搜索结果页、会话链接和临时跳转链接；
- DOI 与题名、作者、来源必须匹配；
- URL、引用日期、DOI 的加入不能替代年、卷、期、页码、出版项等原有题录字段。

### 第六步：事实核验

至少核对：

- 作者及顺序；
- 题名；
- 文献类型；
- 期刊名或会议录名；
- 年、卷、期；
- 页码或文章编号；
- 出版地、出版者；
- 学位授予单位；
- 报告号、标准号、专利号；
- URL、引用日期和 DOI。

正式来源之间冲突时，优先文献本身的正式页面、题名页或版权页，并明确保留冲突和采用依据。

### 第七步：输出

单条文献默认：

```text
最终格式：
[1] ...

核验状态：已核实 / 部分核实 / 信息不足
待确认：无，或列出字段
```

批量文献默认：

| 编号 | 最终参考文献 | 核验状态 | 待确认字段 |
|---|---|---|---|

用户只要求最终结果时，可以省略过程说明，但不得静默填补无法核实的字段。

## 质量门槛

提交前检查：

- 文献类型和载体代码属于 GB/T 7714—2015 的代码体系；
- 作者人数规则正确；
- 西文姓名形式符合本标准写法；
- 会议论文具有正确的析出文献结构；
- 期刊论文没有因在线获取而误判为电子公告；
- 电子资源的 `/OL`、引用日期和获取路径完整；
- DOI 真实且与文献匹配；
- 页码和文章编号未混淆；
- 出版地、出版者、学位单位等均有证据；
- 未用常识或机构所在地补造缺失字段；
- 学校或期刊模板与国标要求存在额外约束时，已按用户要求单独处理。
