# GB/T 7714—2015 参考文献生成器

## 目标

根据 DOI、URL、正式出版页面、论文 PDF、题名或不完整题录，生成符合 GB/T 7714—2015 的参考文献，并在用户提供正文时同时生成或整理正文标注。

必须同时保证：

1. **格式正确**：责任者、文献类型、字段顺序、出版项、正文标注体系符合 GB/T 7714—2015；
2. **题录真实**：作者、题名、年卷期、页码、文章编号、出版项、编号字段、URL、DOI 等事实字段有证据；
3. **正文与文后闭环**：正文标注与文后条目一一对应，不静默制造、删除或错配文献。

开始前阅读：

- `references/gbt7714-2015-quick-reference.md`

需要回归测试时读取：

- `references/regression-tests.md`

## 适用范围

支持普通图书、会议录、汇编、专著析出文献、会议论文、连续出版物整体、期刊/报纸析出文献、学位论文、报告、标准、专利、数据库、计算机程序、电子公告、档案、舆图、数据集和其他资源；支持印刷、磁带、磁盘、光盘、联机网络；支持顺序编码制和著者-出版年制。

用户有学校、期刊或项目模板时优先服从模板；模板与本标准默认形式不同的地方单独说明。

## 默认策略

### 引用体系

- 默认顺序编码制；
- 用户已有编号时保留，除非要求重排；
- 用户明确要求著者-出版年制时，必须同时切换正文标注、文后年份位置和文后排序，不能只删除编号；
- 不无说明混用两种体系。

### 类型标识

GB/T 7714—2015 将文献类型标识列为选择项目。本 skill 默认保留 `[M]`、`[J]`、`[C]` 等；用户模板要求省略时再省略。

### publication-first

先判定资源本质，再判定载体：

- 正式期刊论文在线获取仍是 `[J/OL]`，不是 `[EB/OL]`；
- 在线报告、学位论文、专利、数据集分别使用 `[R/OL]`、`[D/OL]`、`[P/OL]`、`[DS/OL]`；
- 独立网页、电子公告等才考虑 `[EB/OL]`；
- `Z` 仅用于确实无法归入既有类型的资源。

## 证据优先级

1. 文献正式首页、题名页、版权页、正式 PDF；
2. 出版者、期刊、会议、大学、政府机构、标准组织正式页面；
3. DOI 正式落地页；
4. Crossref、PubMed、国家期刊平台、图书馆目录等权威题录；
5. 普通聚合页面仅作检索线索。

PDF 文件名、PDF 元数据、搜索摘要和 AI 摘要不得替代正式题录证据。

## 执行流程

### 1. 建立内部元数据

至少记录：

```text
citation_system:
reference_role: cited / reading / unknown
source_type:
carrier:
authors:
corporate_author:
title:
other_title_info:
container_authors:
container_title:
year:
volume:
issue:
supplement:
combined_issue:
pages:
article_number:
place:
publisher:
edition:
degree_institution_place:
degree_institution:
report_number:
standard_number:
patent_number:
published_or_updated_date:
cited_date:
url:
doi:
language:
evidence:
unresolved_fields:
```

未知事实字段先留空，不猜。

### 2. 判定文献类型和载体

类型代码：

- `M` 普通图书/专著
- `C` 会议录
- `G` 汇编
- `N` 报纸
- `J` 期刊
- `D` 学位论文
- `R` 报告
- `S` 标准
- `P` 专利
- `DB` 数据库
- `CP` 计算机程序
- `EB` 电子公告
- `A` 档案
- `CM` 舆图
- `DS` 数据集
- `Z` 其他

载体代码：`MT`、`DK`、`CD`、`OL`。

低频类型按其真实资源属性选择代码，再套用专著、析出文献、连续出版物或电子资源的对应结构，不一律改成 `EB` 或 `Z`。

### 3. 规范责任者

- 不超过 3 位全部著录；超过 3 位只著录前 3 位，中文加“等”，西文加 `et al.`；
- 欧美著者姓在前并大写，名可缩写且不加缩写点；
- 汉语拼音姓名姓全大写，名可全拼或按汉字拼音首字母缩写；
- 无责任者：顺序编码制可直接从题名开始；著者-出版年制使用“佚名”或相应词；
- 西文机关团体上下级按正式来源自上而下分级，以 `.` 分隔；中文机关团体按正式名称；
- 作者数量、顺序、机构层级必须核实。

### 4. 处理出版项缺失

#### 出版地

- 非电子中文文献无出版地：`[出版地不详]`；
- 非电子外文文献无出版地：`[S.l.]`；
- 无出版地电子资源可省略；
- 不用会议举办地、作者单位所在地、域名等推断出版地。

#### 出版者

- 非电子中文文献无出版者：`[出版者不详]`；
- 非电子外文文献无出版者：`[s.n.]`；
- 无出版者电子资源可省略；
- 多出版者按正式信息取第一个或处于显要位置者。

#### 出版年

无法确定时依次使用：

1. 版权年 `c1988`；
2. 印刷年 `1995印刷`；
3. 估计年 `[1936]`。

不得用网页上传日期、抓取日期或搜索引擎日期代替出版年。

### 5. 按结构生成文后条目

#### 普通图书 / 专著

```text
[序号] 主要责任者. 题名: 其他题名信息[M]. 其他责任者. 版本项. 出版地: 出版者, 出版年: 引文页码.
```

第 1 版通常省略。引文参考文献按实际引用著录引文页码；阅读型专著可不著录引文页码。

#### 专著中的析出文献 / 会议论文

```text
[序号] 析出文献主要责任者. 析出文献题名[C]//专著主要责任者. 专著题名. 出版地: 出版者, 出版年: 析出文献页码.
```

会议论文必须有正确的 `//` 析出结构。会议举办地不能自动当出版地。

#### 连续出版物整体

```text
[序号] 主要责任者. 题名[J]. 起始年, 卷(期)-终止年, 卷(期). 出版地: 出版者, 起始出版年-终止出版年.
```

持续出版时允许开放区间，例如 `1984, 1(1)-.` 和 `1984-.`。

#### 期刊论文 / 连续出版物析出文献

```text
[序号] 主要责任者. 题名[J]. 期刊名, 年, 卷(期): 页码.
```

在线形式：

```text
[序号] 主要责任者. 题名[J/OL]. 期刊名, 年, 卷(期): 页码[引用日期]. 获取和访问路径. DOI:10.xxxx/xxxx.
```

边界：

- 文章编号按文章编号保留，不伪造页码；
- 增刊保留如 `22(增刊2)`；
- 合期保留如 `(9/10)`；
- 连续刊载可在同一条中以分号继续列后续年卷期页。

#### 报纸

```text
[序号] 主要责任者. 题名[N]. 报纸名, YYYY-MM-DD(版次).
```

在线报纸用 `[N/OL]`。

#### 学位论文

```text
[序号] 主要责任者. 题名[D]. 所在地: 学位授予单位, 年: 引文页码.
```

在线形式用 `[D/OL]`。

#### 报告

```text
[序号] 主要责任者. 题名: 报告号[R]. 出版地: 出版者, 出版年: 引文页码.
```

无正式报告号时不编造；在线形式用 `[R/OL]`。

#### 标准

```text
[序号] 主要责任者. 标准名称: 标准号[S]. 出版地: 出版者, 出版年: 引文页码.
```

发布日期、实施日期、出版年分别核实。

#### 专利

```text
[序号] 专利申请者或所有者. 专利题名: 专利号[P]. 公告日期或公开日期.
```

日期使用 `YYYY-MM-DD`；在线形式可用 `[P/OL]`。

#### DB / CP / EB / DS / A / CM / G / Z

按真实类型选择代码。联机资源可按：

```text
[序号] 主要责任者. 题名[类型/OL]. 版本项或必要信息. 出版地: 出版者, 出版年: 引文页码(更新或修改日期)[引用日期]. 获取和访问路径. DOI:10.xxxx/xxxx.
```

纯在线资源没有实际出版地、出版者时允许省略，不为凑模板补造。

### 6. 页码与文章编号

- 阅读型期刊/析出文献著录起讫页或起始页；
- 引文参考文献著录实际引用信息所在页；
- 会议论文页码来自会议录；
- article number 不改成页码范围；
- 数据库记录号、检索号、内部 ID 不当页码。

### 7. 在线信息与 DOI

- 引用日期：`[YYYY-MM-DD]`；
- 更新/修改日期只有正式来源明确给出时才写 `(YYYY-MM-DD)`；
- URL 指向实际资源、正式落地页或稳定地址；
- DOI 必须与题名、作者、来源匹配；
- URL 已完整包含 DOI 时避免无意义重复；URL 不含 DOI 且正式来源有 DOI 时优先写 `DOI:10.xxxx/xxxx`；
- 没有 DOI 或无法核实时不得猜。

### 8. 生成正文标注

#### 顺序编码制

- 单篇：`[3]`；
- 同处多篇：`[2,4,6-9]`；
- 同一文献再次引用沿用首次编号；
- 需要引文页码时，具体页码按标准放在序号方括号外，不重复创建文后条目。

#### 著者-出版年制

- 基本：`(著者, 年)`；
- 正文已出现著者姓名：只标 `(年)`；
- 中国多著者：第一著者 + “等”；
- 欧美多著者：第一著者姓 + `et al.`；
- 同一著者同一年：`2020a`、`2020b`……，正文文后一致；
- 多次引用同一文献时著者与年份不变，具体引文页码按标准放在圆括号外。

### 9. 正文-文后闭环

当用户提供正文和文后条目时必须双向检查：

- 正文每个编号或著者-年份标注都必须找到唯一对应文后条目；
- 文后每个作为“引文参考文献”的条目都应能在正文找到对应标注；
- 正文有引用但文后缺条目：列为缺失条目，不得猜测补成其他文献；
- 文后有条目但正文未引用：列为孤立条目，不自动删除；如果用户说明它是阅读型参考文献则可保留；
- 同一文献被多个编号重复引用时，应合并到首次编号并同步正文；
- 同一编号对应多条不同文献时必须报冲突；
- 著者-出版年制的 `a/b/c` 必须正文文后一致。

### 10. 著者-出版年制文后排序

1. 先按文种集中，可分中文、日文、西文、俄文、其他；
2. 各文种按著者字顺；
3. 同一著者按出版年；
4. 同著者同年用 `a/b/c`；
5. 中文可按拼音字顺或笔画笔顺；
6. 年份紧接主要责任者之后，不保留 `[1]` 编号。

### 11. 事实核验

至少核对：作者及顺序、题名、文献类型/载体、来源名称、年卷期、增刊/合期、页码/文章编号、出版地、出版者、学位单位、报告号、标准号、专利号、日期、URL、DOI。

正式来源冲突时优先文献自身正式页面、题名页或版权页，并记录冲突与采用依据。


批量：

有正文时再给出：

```text
正文引用数：

```
