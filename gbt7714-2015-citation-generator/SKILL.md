# GB/T 7714—2015 参考文献生成器

## 目标

根据用户提供的 DOI、URL、正式出版页面、论文 PDF、题名或不完整题录，生成符合 GB/T 7714—2015 的参考文献。

必须同时保证两件事：

1. **格式正确**：责任者、文献类型、字段顺序、标点、出版项、正文标注体系符合 GB/T 7714—2015；
2. **题录真实**：作者、题名、年卷期、页码、文章编号、出版地、出版者、报告号、标准号、专利号、URL、DOI 等事实字段有来源，不凭猜测补造。

开始前阅读：

- `references/gbt7714-2015-quick-reference.md`

## 适用范围

支持：

- 普通图书、会议录、汇编；
- 专著或会议录中的析出文献；
- 连续出版物整体；
- 期刊、报纸等连续出版物中的析出文献；
- 学位论文、报告、标准、专利；
- 数据库、计算机程序、电子公告、档案、舆图、数据集及其他资源；
- 印刷、磁带、磁盘、光盘、联机网络等载体；
- 顺序编码制与著者-出版年制；
- 正文标注与文后参考文献的联合生成。

用户学校、期刊或项目有明确模板时，优先服从用户模板；如模板与本标准默认形式不同，输出时将“模板要求”和“2015 默认规则”分开说明。

## 接受的输入

- 一个或多个 DOI；
- 出版者、期刊、会议、大学、政府机构、标准组织或数据库正式页面；
- 论文、报告、学位论文、标准、专利等正式 PDF；
- 用户粘贴的题名、作者、年份等不完整题录；
- 已有参考文献，需要核实后重新生成；
- 正文 + 文后参考文献，需要同时生成或重排；
- 学校、期刊或项目给出的特殊格式模板。

## 默认策略

能从上下文确定时直接执行，不重复询问。确有歧义且会改变最终结果时，最多询问一个关键问题；若用户要求直接完成，则按证据最充分方案执行，并把仍无法确定的事实字段列为待确认。

### 引用体系

- 默认采用顺序编码制 `[1]`、`[2]`……；
- 用户已有编号时保留原编号，除非要求重排；
- 用户明确要求著者-出版年制时，切换整套文后排序和正文标注规则，不只删除编号；
- 不得在同一参考文献表中无说明地混用两种体系。

### 文献类型标识

GB/T 7714—2015 将文献类型标识列为选择项目，但本 skill 默认保留类型标识，以避免歧义并符合常见中文论文实践。用户模板明确要求省略时再省略。

### 载体判断

采用 `publication-first`：

- 先判断资源本质是什么，再判断载体；
- 正式期刊论文即使从网页下载，仍是 `J`，在线形式为 `[J/OL]`，不是 `[EB/OL]`；
- 报告、学位论文、专利、数据集等在线获取时分别使用 `[R/OL]`、`[D/OL]`、`[P/OL]`、`[DS/OL]`；
- 独立网页、电子公告、机构页面等才使用 `[EB/OL]`；
- 无法归类时才考虑 `Z`，不得用 `Z` 掩盖尚未完成的类型判断。

### DOI

- DOI 只从正式 PDF、正式出版页面、DOI 落地页或权威题录服务获取；
- DOI 必须与题名、作者、来源等字段匹配；
- 获取路径中已完整包含 DOI 时可避免机械重复；若路径不含 DOI 而正式来源给出 DOI，统一优先写为 `DOI:10.xxxx/xxxx`；
- 资源没有 DOI 或无法核实时，不得伪造，标记为“无 DOI”或“未核实”。

## 证据优先级

### 有 PDF 时

优先检查：

1. 首页、题名页、版权页；
2. 页眉、页脚和末页；
3. DOI、报告号、标准号、专利号所在位置；
4. 会议录封面、目录、版权页和出版信息页。

PDF 文件名和 PDF 元数据只能作线索，不能替代页面证据。

### 需要联网时

按以下优先级核实：

1. 文献正式首页、正式 PDF、题名页或版权页；
2. 出版者、期刊、会议、大学、政府机构、标准组织正式页面；
3. DOI 正式落地页；
4. Crossref、PubMed、国家期刊平台、图书馆目录等权威题录服务；
5. 普通聚合网站仅作检索线索。

搜索结果摘要、AI 摘要或二次转载不得作为唯一题录依据。

## 执行流程

### 第一步：建立元数据记录

每条文献先建立内部记录：

```text
citation_system: numeric / author-date
reference_role: cited / reading / unknown
source_type:
carrier:
authors:
corporate_author:
title:
other_title_info:
container_authors:
container_title:
year:
volume:
issue:
supplement:
combined_issue:
pages:
article_number:
place:
publisher:
conference_proceedings:
degree_institution_place:
degree_institution:
report_number:
standard_number:
patent_number:
edition:
published_or_updated_date:
cited_date:
url:
doi:
language:
evidence:
unresolved_fields:
```

未知事实字段留空，先不猜。

### 第二步：判定类型和载体

文献类型代码：

- `M` 普通图书/专著
- `C` 会议录
- `G` 汇编
- `N` 报纸
- `J` 期刊
- `D` 学位论文
- `R` 报告
- `S` 标准
- `P` 专利
- `DB` 数据库
- `CP` 计算机程序
- `EB` 电子公告
- `A` 档案
- `CM` 舆图
- `DS` 数据集
- `Z` 其他

载体代码：`MT`、`DK`、`CD`、`OL`。

低频类型不单独发明新语法：先根据其真实资源属性选择类型代码，再按专著、析出文献、连续出版物或电子资源的对应结构著录。

### 第三步：规范责任者

- 不超过 3 个同一著作方式的责任者全部著录；
- 超过 3 个只著录前 3 个，中文加“等”，西文加 `et al.`；
- 欧美著者姓在前并大写，名可缩写且缩写后不加点；
- 汉语拼音姓名姓全大写，名可全拼或按每个汉字取拼音首字母；
- 无责任者或责任者情况不明：顺序编码制可省略责任者直接从题名开始；著者-出版年制用“佚名”或相应词；
- 西文机关团体有上下级时按正式来源自上而下分级著录并以 `.` 分隔；中文机关团体按正式名称著录；
- 作者人数、顺序、机构层级均需来源支持。

### 第四步：处理出版项缺失

此处必须区分“事实未知”和“标准缺省写法”。

#### 出版地

- 非电子中文文献确实无出版地：`[出版地不详]`；
- 非电子外文文献确实无出版地：`[S.l.]`；
- 无出版地的电子资源可省略；
- 不得用会议举办地、作者单位所在地、机构所在地或域名推断出版地。

#### 出版者

- 非电子中文文献确实无出版者：`[出版者不详]`；
- 非电子外文文献确实无出版者：`[s.n.]`；
- 无出版者的电子资源可省略；
- 多个出版者时只取第一个或处于显要位置者，除非用户模板另有要求。

#### 出版年

无法确定出版年时依次采用：

1. 版权年，如 `c1988`；
2. 印刷年，如 `1995印刷`；
3. 估计出版年，如 `[1936]`。

不得把网页抓取日期、上传日期或搜索引擎日期冒充出版年。

### 第五步：按类型生成条目

#### 普通图书 / 专著

```text
[序号] 主要责任者. 题名: 其他题名信息[M]. 其他责任者. 版本项. 出版地: 出版者, 出版年: 引文页码.
```

第 1 版通常不著录。专著作为引文参考文献时按实际引用著录引文页码；作为阅读型参考文献时可不著录引文页码。

#### 专著中的析出文献 / 会议录论文

```text
[序号] 析出文献主要责任者. 析出文献题名[C]//专著主要责任者. 专著题名: 其他题名信息. 版本项. 出版地: 出版者, 出版年: 析出文献页码.
```

会议论文必须检查 `//` 后是否为正式会议录或论文集信息。会议举办地与出版地不是同一字段。

#### 连续出版物整体

```text
[序号] 主要责任者. 题名: 其他题名信息[J]. 起始年, 卷(期)-终止年, 卷(期). 出版地: 出版者, 起始出版年-终止出版年.
```

仍持续出版时保留开放区间，例如：

```text
1984, 1(1)-. 武汉: 某出版者, 1984-.
```

#### 期刊论文 / 连续出版物析出文献

```text
[序号] 主要责任者. 题名[J]. 期刊名, 年, 卷(期): 页码.
```

在线形式：

```text
[序号] 主要责任者. 题名[J/OL]. 期刊名, 年, 卷(期): 页码[引用日期]. 获取和访问路径. DOI:10.xxxx/xxxx.
```

边界处理：

- 正式文章编号保留为文章编号，不伪造页码区间；
- 增刊保留正式增刊标识，例如 `22(增刊2)`；
- 合期保留正式合期号，例如 `(9/10)`；
- 连续刊载的后续部分可在同条内以分号继续著录后续年卷期页，不必无理由拆条。

#### 报纸文章

```text
[序号] 主要责任者. 题名[N]. 报纸名, YYYY-MM-DD(版次).
```

在线报纸使用 `[N/OL]` 并补充引用日期、获取路径；有 DOI 时如实著录。

#### 学位论文

```text
[序号] 主要责任者. 题名[D]. 所在地: 学位授予单位, 年: 引文页码.
```

在线学位论文使用 `[D/OL]`。

#### 报告

```text
[序号] 主要责任者. 题名: 报告号[R]. 出版地: 出版者, 出版年: 引文页码.
```

报告号有则著录，无则不编造。在线报告使用 `[R/OL]`。

#### 标准

```text
[序号] 主要责任者. 标准名称: 标准号[S]. 出版地: 出版者, 出版年: 引文页码.
```

标准发布日期、实施日期与出版年分开核实，不机械互换。

#### 专利

```text
[序号] 专利申请者或所有者. 专利题名: 专利号[P]. 公告日期或公开日期.
```

日期采用 `YYYY-MM-DD`。在线专利可用 `[P/OL]` 并补充引用日期和获取路径。

#### 数据库 / 计算机程序 / 电子公告 / 数据集 / 档案 / 舆图 / 汇编 / 其他

根据真实资源类型选择 `DB`、`CP`、`EB`、`DS`、`A`、`CM`、`G`、`Z`，再按资源实际结构著录。

联机资源常用结构：

```text
[序号] 主要责任者. 题名: 其他题名信息[类型/OL]. 版本项或必要信息. 出版地: 出版者, 出版年: 引文页码(更新或修改日期)[引用日期]. 获取和访问路径. DOI:10.xxxx/xxxx.
```

纯在线资源实际没有出版地、出版者等字段时允许省略，不为凑模板补造。

### 第六步：处理页码与文章编号

- 阅读型的期刊或析出文献著录文章起讫页或起始页；
- 引文参考文献著录实际引用信息所在页；
- 会议论文使用其在会议录中的正式页码；
- 文章编号单独保留，不改成伪页码；
- 数据库记录号、检索字段、内部编号不得当页码。

### 第七步：处理在线信息

- `/OL` 与真实基本类型组合；
- 引用日期统一 `[YYYY-MM-DD]`；
- 更新或修改日期只有正式来源明确给出时才写为 `(YYYY-MM-DD)`；
- URL 指向实际资源、正式落地页或稳定访问地址，避免搜索结果页、会话链接和临时跳转链接；
- URL、引用日期、DOI 不能替代年、卷、期、页码、文章编号或出版项等原题录字段。

### 第八步：生成正文标注

#### 顺序编码制

- 单篇：`[3]`；
- 多篇：`[2,4,6-9]`；
- 同一文献重复引用继续用同一编号；
- 需要引文页码时，将具体页码按标准要求放在序号方括号外，不重复生成文后条目。

#### 著者-出版年制

- 基本形式：`(著者, 年)`；
- 正文已经出现著者姓名：只补 `(年)`；
- 中国多著者：第一著者 + “等”；
- 欧美多著者：第一著者姓 + `et al.`；
- 同一著者同一年多篇：`2020a`、`2020b`……，正文与文后同步；
- 多次引用同一文献时，著者与出版年不变，具体引文页码按标准放在圆括号外。

### 第九步：著者-出版年制文后排序

采用著者-出版年制时：

1. 先按文种集中，可分中文、日文、西文、俄文、其他文种；
2. 各文种内按著者字顺；
3. 同一著者按出版年排列；
4. 同一著者同一年按 `a`、`b`、`c`……区分；
5. 中文可按汉语拼音字顺或笔画笔顺；
6. 文后年份紧接主要责任者后，不保留顺序编码编号。

### 第十步：事实核验

至少核对：

- 作者及顺序、机构作者；
- 题名及其他题名信息；
- 文献类型与载体；
- 期刊名、会议录名或载体文献名；
- 年、卷、期、增刊、合期；
- 页码或文章编号；
- 出版地、出版者、学位授予单位；
- 报告号、标准号、专利号；
- 公告/公开日期、更新日期、引用日期；
- URL 与 DOI。

正式来源冲突时，优先文献自身正式页面、题名页或版权页，并记录冲突与采用依据。

## 输出

### 单条文献

```text
最终格式：
[1] ...

正文标注：
[1]

核验状态：已核实 / 部分核实 / 信息不足
待确认：无 / 字段列表
```

用户未要求正文标注时，可省略“正文标注”。

### 批量文献

| 编号/著者-年键 | 最终参考文献 | 核验状态 | 待确认字段 |
|---|---|---|---|

著者-出版年制时用 `作者-年份` 或 `作者-年份字母` 作为内部识别键，不强行添加 `[1]`。

用户只要求最终结果时，可以省略过程说明，但不得静默填补无法核实的事实字段。

## 质量门槛

提交前逐项确认：

- [ ] 使用的是 GB/T 7714—2015 规则；
- [ ] 顺序编码制或著者-出版年制从正文到文后保持一致；
- [ ] `4+` 作者已正确处理；
- [ ] 无责任者已按引用体系处理；
- [ ] 文献类型与载体真实匹配；
- [ ] 会议论文具有正确的 `//` 析出结构；
- [ ] 期刊论文没有因为在线获取被误写为 `[EB/OL]`；
- [ ] 非电子文献缺出版地/出版者时使用 `[出版地不详]` / `[S.l.]` / `[出版者不详]` / `[s.n.]`；
- [ ] 出版年未知时按版权年→印刷年→估计年的顺序处理；
- [ ] 连续出版物整体、增刊、合期、连续刊载均能按原题录保留；
- [ ] 页码与文章编号未混淆；
- [ ] `DB/CP/DS/A/CM/G/Z` 等低频类型没有被一律改成 `EB`；
- [ ] 在线资源的 `/OL`、引用日期、获取路径处理完整；
- [ ] DOI 真实且匹配，没有根据题名猜测；
- [ ] 出版地、出版者、学位单位、报告号、标准号、专利号均有证据或按标准缺省形式处理；
- [ ] 著者-出版年制同著者同年文献使用 `a/b/c` 且正文文后一致；
- [ ] 正文多篇顺序编码能够正确压缩连续序号，例如 `[2,4,6-9]`；
- [ ] 用户模板的额外约束已单独处理。
