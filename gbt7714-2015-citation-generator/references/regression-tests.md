# GB/T 7714—2015 回归测试集

本测试集用于人工或代理回归检查 `gbt7714-2015-citation-generator`。样例为合成数据，重点测试规则行为，不用于题录真实性验证。

## 通过条件

- 生成结果符合对应规则；
- 不凭猜测补事实字段；
- 缺失字段按标准缺省规则处理；
- 顺序编码制与著者-出版年制不混用；
- 文献基本类型与载体分开判断。

## T01 中文非电子文献缺出版地与出版者

输入元数据：中文图书，作者“张三”，题名“测试图书”，出版年 2010；正式来源确认没有出版地和出版者。

期望核心：

```text
张三. 测试图书[M]. [出版地不详]: [出版者不详], 2010.
```

不得直接把出版地、出版者留空，也不得凭机构名称猜出版地。

## T02 外文非电子文献缺出版地与出版者

输入元数据：英文图书，作者 `SMITH J`，题名 `Test Book`，出版年 2010；正式来源无出版地和出版者。

期望核心：

```text
SMITH J. Test Book[M]. [S.l.]: [s.n.], 2010.
```

## T03 出版年无法确定

分别测试：

1. 有版权年 1988 → `c1988`；
2. 无版权年但有印刷年 1995 → `1995印刷`；
3. 仅能估计 1936 → `[1936]`。

不得用网页上传日期或检索日期代替出版年。

## T04 超过 3 位作者

输入：中文作者 A、B、C、D；英文作者 `ALPHA A`、`BETA B`、`GAMMA C`、`DELTA D`。

期望：

- 中文：前三位 + “等”；
- 英文：前三位 + `et al.`。

## T05 无责任者

同一条匿名资源分别生成：

- 顺序编码制：允许省略责任者，直接从题名开始；
- 著者-出版年制：使用“佚名”或相应词作为第一要素。

## T06 会议论文析出结构

输入：作者、论文题名、会议录题名、出版地、出版者、年份、页码均完整。

期望必须包含：

```text
论文题名[C]//会议录题录...
```

不得把会议举办地自动当出版地。

## T07 在线期刊类型保持

输入：正式期刊论文，有 URL 和引用日期。

期望：`[J/OL]`。

不得生成 `[EB/OL]`。

## T08 连续出版物整体

输入：某期刊 1984 年创刊，卷期从 `1(1)` 开始，仍持续出版，出版地和出版者已知。

期望能够生成开放区间：

```text
1984, 1(1)-. ... 1984-.
```

不得误套单篇期刊论文模板。

## T09 增刊、合期与连续刊载

分别测试：

- 增刊：`22(增刊2)`；
- 合期：`2001(9/10): 36-39`；
- 连续刊载：后续年卷期页在同一条中以分号继续著录。

不得丢失增刊/合期标识。

## T10 低频类型

输入分别为：数据库、计算机程序、数据集、档案、舆图、汇编。

期望类型分别保留：

```text
DB / CP / DS / A / CM / G
```

在线数据库、数据集可组合为 `[DB/OL]`、`[DS/OL]`，不得一律改成 `EB` 或 `Z`。

## T11 著者-出版年制同著者同年

输入：同一著者在 2020 年有两篇不同文献。

期望：

- 文后年份区分为 `2020a`、`2020b`；
- 正文对应使用相同的 `a/b`；
- 文后先按文种，再按著者字顺和出版年排序；
- 不出现顺序编码 `[1]`、`[2]`。

## T12 顺序编码制正文多文献

输入正文同一位置引用编号 2、4、6、7、8、9。

期望：

```text
[2,4,6-9]
```

同一文献再次出现时继续使用首次编号。

## T13 DOI 边界

测试：

1. URL 不含 DOI，正式来源给出 DOI → 著录 `DOI:10.xxxx/xxxx`；
2. URL 已完整包含 DOI → 避免无意义重复；
3. 题名相似但 DOI 未核实 → 不得猜 DOI；
4. DOI 与题名/作者不匹配 → 标为事实冲突，不能静默使用。

## T14 页码与文章编号

输入：期刊正式题录使用文章编号 `e12345`，无传统页码。

期望保留 `e12345`，不得生成伪页码范围。

数据库记录号也不得当作页码。

## T15 正文与文后闭环

给定正文实际引用 `[1]`、`[2]`、`[4]`，文后存在 `[1]`、`[2]`、`[3]`、`[4]`。

生成器在联合生成/整理场景中应能识别 `[3]` 为正文未使用条目，并在用户要求引文参考文献闭环时提示处理；不得自动改写成其他文献。
