# 1. 目标

本技能用于 PCB 投板前的最终交叉审核。

主线：

**背景约束 → PDF 原理图 → 网表真实连接 → BOM 实际器件 → 官方手册/典型应用 → 计算校核 → 风险分级 → 是否可投板**

最终回答必须明确：

1. 是否存在会导致电路不能正常工作的连接错误。
2. 电阻、电容、电感、磁珠、保险丝、TVS、DC/DC 等参数是否合理。
3. 是否违反关键器件官方推荐电路、绝对最大值、输入范围或供电要求。
4. 电源电压、电流、功率是否足够。
5. BOM 中是否存在可以统一的元器件，或“参数相同却选了多个型号”的情况。
6. 制造商型号的真实封装是否与 PCB Footprint 匹配。
7. 是否缺少必要保护，或保护器件参数不合理。
8. 当前版本是否可以进入 PCB/投板阶段。

# 2. 输入

优先接收以下 4 类输入：

- `background`：设计背景、输入输出范围、信号类型、频率、采样率、隔离要求、电源条件、外部采样电阻等。
- `schematic_pdf`：完整原理图 PDF，必须尽可能包含全部 Sheet。
- `bom`：`.xlsx/.xls/.csv`，至少包含 RefDes、Value、MPN/LibRef、Footprint；若有容差、额定电压、功率、介质、封装尺寸更好。
- `netlist`：Altium `.NET` 或其他可解析网表。

可选输入：

- 芯片/模块 datasheet、application note、reference design。
- PCB 截图或 PCB 文件，用于布局、回流、爬电、隔离区复核。
- 上一版审核报告，用于确认问题是否修复。

若缺失关键信息，不得把“未验证”写成“正常”。

# 3. 信息可信度与冲突处理

多个文件冲突时，不允许默认任选一个。

按以下规则处理：

1. **网表**决定“电气上到底有没有连上”。PDF 上看似有 Net Label，不代表 Netlist 中一定成立。
2. **PDF**用于理解电路意图、功能分区、标注、设计注释和手册拓扑。
3. **BOM**决定实际采购什么器件、什么型号、什么封装。
4. **官方 datasheet / 官方 application note**决定器件范围、推荐参数、绝对最大值和封装。
5. **背景说明**决定设计目标与量程。

若 PDF、BOM、NET 的 RefDes、版本或参数不一致，先列为“版本一致性问题”，不要继续假定三者来自同一版本。

# 4. 审核流程

## 4.1 版本一致性检查

先检查：

- PDF 日期/Revision。
- BOM 导出时间/版本。
- 网表导出时间/版本。
- 是否存在 `U? / R? / C? / FB?`。
- PDF 中的 RefDes 集合与 BOM、NET 是否一致。
- PDF 显示已连接但 NET 缺失的引脚。

若版本不一致，报告中必须单独列出。

## 4.2 连线审核

从 Netlist 建立：

`RefDes-Pin → Net`

重点检查：

- 未进入任何 Net 的有效引脚。
- 单节点 Net。
- 电源脚/地脚悬空。
- NC 脚是否被错误使用。
- Net Label 是否实际吸附。
- 同名电源是否误跨隔离域。
- 原边地、次边地、保护地、机壳地是否被意外连接。
- 多个隔离域之间是否通过 LED、电阻、测试点、屏蔽、参考地等“隐蔽路径”串起来。
- 差分输入正负是否接反。
- 运放正负输入、反馈网络是否接反。
- DC/DC 输入/输出回路是否使用正确返回端。
- 输出信号是否真正到达连接器。
- 连接器 pin mapping 是否和外部板一致。

隔离类电路必须特别检查：

**隔离电源返回端、指示灯返回端、测量参考端、滤波电容返回端必须属于同一隔离域。**

## 4.3 参考电路/手册一致性

对关键 IC 和电源模块，优先使用制造商官方资料。

逐项比对：

- 供电范围。
- 必需去耦电容。
- VCAP / LDO_OUT / HLD0_IN / DCDC_IN 等专用引脚推荐网络。
- 输入滤波结构。
- 输出滤波结构。
- DC/DC 推荐 `Cin / Lin / Cs / Lout / Cout`。
- 芯片差分输入满量程。
- 推荐磁珠或磁性元件型号。
- 是否有最小/最大容性负载限制。
- 是否明确要求某器件贴近引脚。

手册中明确给出范围时，以范围判断；不要因为个人经验擅自删除厂家推荐的 LC/RC 网络。

## 4.4 电阻审核

检查：

- 阻值是否满足量程和增益。
- 分压链每颗电阻的电压应力。
- 单颗功耗与封装额定功率。
- 高压电阻的最大工作电压，不只看功率。
- 运放四电阻差分网络比例是否成对一致。
- 容差是否满足增益/CMRR要求。
- LED 限流电阻是否合理。
- 串联保护电阻是否过大影响带宽，或过小失去限流作用。

常用计算：

### DC 分压

`Vchip = Vin × Rbottom / (Rtop + Rbottom)`

### AC 正弦峰值

`Vchip_pk = Vin_rms × sqrt(2) × Rbottom / (Rtop + Rbottom)`

### 串联分压链电流

`I = Vin / Rtotal`

### 单颗电阻功耗

`P = I²R`

同时核对该电阻两端最大电压是否小于 datasheet 的 working voltage。

## 4.5 电容审核

检查：

- 容值。
- 容差。
- 额定电压。
- 介质：C0G/NP0、X7R、铝电解等。
- DC Bias 下有效电容。
- 极性。
- 官方推荐值/范围。
- 输入/输出滤波截止频率。

RC 低通：

`fc = 1 / (2πRC)`

若设计注释标记了目标带宽，必须反算并核对。

高压电源母线上的 MLCC 不只检查“50V > 28V”，还要提醒核查 DC Bias 衰减。

## 4.6 电感/磁珠审核

区分：

- 功率电感：检查 L、额定电流、饱和电流、DCR、封装。
- 磁珠：检查目标频段阻抗、额定电流、DCR、厂商推荐型号。

若厂家推荐电路给出 `Lin/Lout` 范围，实际值只要位于范围内且额定电流足够即可。

额外 LC 网络若不是厂家推荐方案，可计算：

`f0 = 1 / (2π√(LC))`

仅将其作为风险提示，不应无依据判定“必然振铃”。

## 4.7 电源预算

对每一条 Rail 建表：

| Rail | 电源模块能力 | 负载组成 | 最坏电流 | 功率 | 裕量 |
|---|---:|---|---:|---:|---:|

原则：

- 用 datasheet 最大/保守电流，不只用典型值。
- 隔离芯片原边/次边分别计入对应电源域。
- 运放双电源按每 Rail 分别统计。
- 加 LED、分压、输出负载和 10%~20% 工程余量。
- 折算到总输入端时考虑 DC/DC 效率。

输出必须给：

- 正常预计输入电流。
- 保守设计输入电流。
- 电源模块是否足够。

## 4.8 BOM 统一与采购风险

这是必做项，不是附加项。

对 BOM 按以下方式归一化：

### A. 参数相同但用了多个 MPN

按器件类别构造“电气参数键”。

电容示例：

`(Value, Tolerance, Voltage, Dielectric, Package)`

电阻示例：

`(Value, Tolerance, Power, WorkingVoltage, TCR, Package)`

若参数键完全相同但 MPN 不同：

- 列出所有 RefDes。
- 比较厂家、纹波、ESR、寿命、温度等隐藏参数。
- 确认可以互换后，建议统一一个型号。

### B. 型号相同但 Footprint 不同

检查是否只是自定义 footprint 名称不同，还是焊盘实际尺寸不同。

### C. MPN 真实封装与 PCB Footprint 不一致

例如：

`0603 型号 → C0805 footprint`

必须列为生产风险。

### D. Footprint 名称误导

例如 footprint 名中带另一个具体器件型号，但实际焊盘尺寸与当前 MPN 完全兼容。

这种情况可以电气上判为“可用”，但建议改名以免采购/生产误解。

### E. 可合并器件

输出格式：

`原型号 A + 原型号 B → 推荐统一型号 → 涉及 RefDes → 原因`

不能只因为“容值一样”就合并。必须至少确认封装、耐压、容差、介质/类型以及关键性能。

## 4.9 封装核对

BOM 中每个具体 MPN，尽量从官方 datasheet 核对：

- Package code。
- Body L/W/H。
- Pitch。
- Pin count。
- 极性/Pin 1。
- 推荐 land pattern。

优先识别：

- 0603/0805/1206 写错。
- SOIC/SO-MOD/TSSOP/QFN 混淆。
- 电解 D×L 与 footprint 不一致。
- 电感长宽对应不上。
- 连接器公母/针数/脚距不匹配。

如果仅凭名称无法确定，写“需打开 Footprint 实测 pad 坐标确认”，不要硬判。

## 4.10 保护审核

按信号入口、电源入口、输出接口分别检查。

### 电源入口

- 保险丝：额定电流、额定电压、分断能力、快/慢断。
- TVS：VRWM、VBR、VC、脉冲功率。
- 反接保护。
- 过压/浪涌保护。
- 输入储能电容。
- EMI/EMC 滤波。

### 高压/模拟输入

- 分压限流。
- 输入钳位。
- 差模/共模过压。
- 高压电阻工作电压。
- 爬电/电气间隙。

### 模拟输出

- 串联电阻。
- ESD/TVS 预留。
- 外部误接电压时是否会反灌运放。

如果用户环境是普通实验室 24/28V 电源和真实航空母线，要明确区分保护等级，不可混为一谈。

# 5. 风险分级

- **P0 — 必须修改**：会导致板子不能工作、隔离被破坏、器件损坏、短路、关键通道悬空、封装无法焊接。
- **P1 — 投板前必须确认**：量程逼近极限、BOM/NET/PDF版本冲突、额定值不明确、保护不足、关键 Footprint 未验证。
- **P2 — 建议优化**：可以工作，但统一物料、改善噪声、提高裕量、减少采购种类。
- **P3 — 备注**：设计取舍或后续测试项，不影响当前功能。

不得把“可能”写成 P0。P0 必须有明确连接、计算、datasheet 或封装证据。

# 6. 输出模板

最终报告严格按以下主线输出，避免堆砌无关条目。

## 6.1 总体判断

一句话：

`当前版本：可投板 / 修正后可投板 / 不建议投板。主要卡点：……`

## 6.2 P0/P1 问题

| 级别 | 位置 | 当前情况 | 为什么有问题 | 修改建议 | 证据 |
|---|---|---|---|---|---|

只放真正重要问题。

## 6.3 参数校核

| 电路/通道 | 当前参数 | 计算结果 | 器件范围/手册 | 判断 |
|---|---|---|---|---|

覆盖：分压、增益、RC、DC/DC滤波、电源预算。

## 6.4 元器件统一建议

| 可统一组 | 当前型号 | 涉及位号 | 是否可合并 | 推荐统一型号 | 原因 |
|---|---|---|---|---|---|

另外单列：

- MPN 与 Footprint 不匹配。
- 同 MPN 多 Footprint。
- 参数相同多 MPN。

## 6.5 保护审核

按：

`28V入口 → 高压输入 → 模拟输出`

只写缺失或需要调整的保护。

## 6.6 最终投板清单

最多 9 项，按动作写：

- [ ] 修正……
- [ ] 重新 Annotate / Compile / 导出 PDF+BOM+NET
- [ ] 确认……

最后一句必须明确：

`以上 P0/P1 完成后，原理图层面可以进入 PCB/投板。`

或：

`仍存在 P0，不建议投板。`

# 7. 回答规则

1. 不复述整份原理图，只报告影响功能、可靠性、生产和采购的内容。
2. 先给判断，再给证据。
3. 确定错误、需要确认、建议优化三者必须分开。
4. 对 datasheet 结论优先引用制造商官方资料。
5. 不因 footprint 名称不同就判定封装错误；要看实际尺寸/焊盘。
6. 不因参数表面相同就合并 MPN；必须核对关键隐藏参数。
7. BOM/NET/PDF 不一致时，先要求统一导出版本。
8. 用户已经说明的外部条件，例如“采样电阻在板外”，不要重复判成缺件。
9. 如果审核的是隔离调理板，优先检查隔离域误连、DC/DC 返回端和高压分压链。
10. 最终目标不是“找尽量多的问题”，而是**尽量找出会让实板失败的问题，并减少无意义的误报**。

# 8. 典型触发语句

- “最后帮我审一下这个隔离调理板。”
- “看看原理图、BOM、网表还有没有问题。”
- “检查阻值容值和参考手册是否一致。”
- “有没有参数一样但是选了不同型号的器件？”
- “检查 BOM 型号和 footprint 有没有对不上的。”
- “这版能不能投板？”
