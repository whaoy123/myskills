# 材料报销验收单自动填报 Skill

## 1. 技能定位与流程

本 Skill 用于将各类采购发票（立创商城、嘉立创 PCB、博信发、京东工业品等各类增值税普通/专用发票 PDF）自动化解析并填报至科研机构/高校单位的《材料验收单 / 办公验收单》（`.xls` / `.xlsx`）中。

```text
发票 PDF 集合 + 验收单原模板 .xls
              ↓
   Python 结构化提取与校验
   (金额/税额/折扣/含税换算)
              ↓
  写入 Excel 第一页（替换示例数据）
   (保留表头、字体、行高、边框、公式)
              ↓
  自动化回读核验（=SUM(...) 动态求和）
              ↓
        交付报销验收单
```

### 核心原则
1. **不手工算账**：所有单价、税额、折扣合并与含税金额计算由 Python 脚本确定性完成；
2. **格式与模板无损**：严格继承原模板的表头（研究所/部门）、列宽、各行行高、SimSun 宋体、细边框和居中规则；
3. **多工作表隔离**：仅更新第一页（材料验收单），保证 Sheet1（历史数据）、Sheet2、Sheet3 等其他工作表 100% 原始不受影响；
4. **动态求和公式**：合计行（E 列）必须写入标准 Excel 动态求和公式 `=SUM(E5:E<末行>)`，而不是写死静态数值。

## 3. 发票解析与数据规范

### 3.1 字段映射关系

| 发票票面信息 | 验收单对应列 (Col 0 ~ 5) | 说明与处理规则 |
| :--- | :--- | :--- |
| **项目名称 + 规格型号** | `材料名称` (Col 0) | 拼接完整名称（如 `*电子元件*贴片电容 CL21B104KBCNNNC`）；折扣行只写项目名 |
| **单 位** | `单位` (Col 1) | 继承发票单位（个、包、片、次等）；折扣行留空 |
| **数 量** | `数量` (Col 2) | 对应正数数量；折扣行留空 |
| **单 价** | `单价` (Col 3) | 含税单价（`价税合计 / 数量`）或不含税单价；折扣行留空 |
| **金 额** | `金额` (Col 4) | 含税金额（`金额 + 税额`）或不含税金额；折扣行填写负数 |
| **销方名称** | `供应商` (Col 5) | 可选，默认为带边框空单元格 |

### 3.2 常见发票类型处理
1. **立创商城发票**：含多行芯片、阻容件、负数折扣行（如 `*电子元件*贴片电阻 -0.71`）及配送费 `*电子元件*配送费`；
2. **嘉立创打板发票**：含打样/批量 PCB 线路板项目（如 `*印制电路板*线路板 Project Outputs...`）；
3. **博信发等连接器发票**：含连接器公头/母头/车针/外壳；
4. **京东工业品发票**：含劳保工具、绝缘手套、快递包装费等。

## 4. 脚本使用指南

### 4.1 依赖环境
- Python 3.8+
- `pdfplumber`, `pypdf`, `xlrd`, `xlwt`, `xlutils`

安装依赖：
```bash
pip install pdfplumber pypdf xlrd xlwt xlutils
```

### 4.2 运行命令

```bash
python scripts/fill_reimbursement_table.py \
  --invoices-dir "/path/to/invoices_folder" \
  --template-xls "templates/材料报销-原模板.xls" \
  --output-xls "/path/to/output_reimbursement.xls" \
  --dept "智能测试与控制技术研究所" \
  --date "2026-08-11"
```

参数说明：
- `--invoices-dir`: 包含所有发票 PDF 的文件夹；
- `--template-xls`: 验收单模板路径；
- `--output-xls`: 输出的新 `.xls` 文件路径；
- `--dept`: 部门名称（默认：智能测试与控制技术研究所）；
- `--date`: 验收单日期（如不指定则自动取发票中最新日期）；
- `--tax-exclusive`: （可选）若指定则按不含税金额填报，默认按含税（价税合计）填报。

## 5. 验收与校验规范

生成完成后必须由脚本进行三重验证：
1. **行数与项数一致性**：发票明细行（包含折扣行与运费）必须 1:1 完整映射到 Excel；
2. **合计金额验证**：核对 `=SUM(E5:E<N>)` 的求和值与全部发票价税合计总和完全相等（精确到分）；
3. **格式与其它 Sheet 完整性**：回读检查 Sheet 0 合并单元格、行高、列宽，确认 Sheet 1~3 无数据丢失。
