# 校准与结果报告

## 1. 校准能消除什么

### 零点校准

通常可消除当时温度和供电条件下的：

- 隔离放大器初始失调；
- 运放初始失调；
- ADC 初始失调；
- 固定的 PCB/漏电偏移。

不能自动消除：

- 失调温漂；
- 噪声；
- 非线性；
- 动态误差；
- 温度或接线变化后的偏移。

### 单点增益校准

在已处理零点的前提下，可共同吸收：

- 分压初始比例误差；
- 隔离器初始增益误差；
- 运放电阻初始增益误差；
- ADC 初始增益误差；
- 基准初始精度误差。

不能自动消除：

- 增益温漂；
- 非线性；
- 频率响应误差；
- 校准点之外的模型误差；
- 长期漂移。

### 两点校准

可同时拟合 offset 和 gain。仍需保留：

- 校准源不确定度；
- INL/非线性；
- 温漂；
- 噪声；
- 频率和动态误差；
- 长期漂移。

### 多点/温度校准

可进一步补偿非线性和温漂，但应计算：

- 拟合残差；
- 插值误差；
- 温度传感器误差；
- 校准网格覆盖；
- 系数量化和版本管理。

## 2. 校准后的误差预算

校准不是“把误差清零”。正确做法是：

1. 删除被校准吸收的初始 offset/gain 项；
2. 新增校准源不确定度；
3. 新增重复性和拟合残差；
4. 从校准温度开始重新计算 drift；
5. 保留非线性、噪声、动态和长期项。

- 调整滤波/采样时间；
- 改善布局或参考源。

## 4. POR 闭环特别说明

对 400 Hz POR：

- 控制目标通常更关注稳定重复性、温漂和三相一致性，而不只是单次绝对精度；
- RMS 计算应使用整周期或同步算法；
- 固定直流 offset 可通过去均值显著减小；
- 模拟 RC 的 400 Hz 幅值衰减必须计算；
- 数字滤波延迟会进入闭环相位裕度，不能只作为“误差”处理；
- 保护阈值预算应使用最坏值，闭环典型性能可另给 RSS。
