# GB/T 7714—2015 快速规则表

本文件用于 `gbt7714-2015-citation-auditor` 自动执行时快速查阅。目标是严格按 GB/T 7714—2015 处理参考文献，不混入其他版本规则。学校、期刊或项目另有模板时，先满足用户模板，再说明其与本标准默认形式的差异。

## 1. 总原则

GB/T 7714—2015 的参考文献表可采用：

- 顺序编码制；
- 著者-出版年制。

本标准对著录项目区分必备项目和选择项目。标注“任选”的项目是选择项目，其余按对应文献结构处理。

文献类型标识在本标准中属于任选项目，但本 skill 默认保留 `[M]`、`[J]`、`[C]` 等类型标识，以提高可读性和一致性；用户模板明确要求省略时再省略。

电子资源必须按实际文献基本类型与载体组合，例如 `[J/OL]`、`[R/OL]`、`[DB/OL]`，不得因为“从网页下载”就统一改成 `[EB/OL]`。

格式合规和题录真实性必须分开判断。未知事实不得凭常识补造，但标准规定的缺省著录形式应按规则生成。

## 2. 两种引用体系

### 2.1 顺序编码制

- 正文按文献首次出现顺序连续编码，使用 `[1]`、`[2]`……；
- 文后参考文献按正文序号排列；
- 同一处引用多篇文献时，在同一方括号内列出序号，各序号以逗号分隔；连续序号可用 `-` 连接，例如 `[2,4,6-9]`；
- 同一文献多次引用时沿用首次编号，不应重新编号；
- 多次引用同一文献且需要标引引文页码时，正文中沿用原序号，并在序号方括号外标注具体引文页码；文后条目不因此重复生成多条。

### 2.2 著者-出版年制

- 正文标注由著者与出版年构成，并置于圆括号中，例如 `(CRANE, 1972)` 或 `(张三, 2020)`；
- 正文已经出现著者姓名时，括号中只著录出版年；
- 多著者文献在正文中：欧美著者仅标第一著者姓并加 `et al.`，中国著者标第一著者姓名并加“等”；
- 同一著者同一年多篇文献，在年份后使用 `a`、`b`、`c`……区分，正文与文后必须一致；
- 文后参考文献先按文种集中，可分中文、日文、西文、俄文、其他文种；再按著者字顺和出版年排列；中文可按汉语拼音字顺或笔画笔顺；
- 著者-出版年制条目中，出版年紧接主要责任者之后，例如 `作者, 2020. 题名[J]...`；
- 多次引用同一文献时，正文仍标著者与出版年，并按标准要求在圆括号外标注具体引文页码。

不得在同一参考文献表中无说明地混用两种体系。

## 3. 主要责任者

- 同一著作方式责任者不超过 3 个：全部著录；
- 超过 3 个：著录前 3 个，中文后加“等”，西文后加 `et al.`；
- 个人著者采用姓在前、名在后的形式；
- 欧美著者的名可缩写，缩写字母后不加缩写点；
- 西文姓氏按本标准示例使用全大写形式，例如 `EINSTEIN A`；
- 用汉语拼音著录中国人姓名时，姓全大写，名可保留全拼，也可取每个汉字拼音首字母，例如 `LI Jiangning` 或 `LI J N`；
- 无责任者或责任者情况不明时，著者-出版年制应著录“佚名”或相应词；顺序编码制可省略主要责任者，直接从题名开始；
- 机关团体责任者按著录信息源著录；西文机关团体有上下级时通常自上而下分级著录并以 `.` 分隔，中文机关团体按原文正式名称著录；
- 不得自行翻译、补写或推断作者、机构层级和作者顺序。

## 5. 常用著录结构

以下模板展示常用字段顺序。没有实际存在的选择项时不要强行补造。

### 5.1 专著及按专著类处理的文献

```text
主要责任者. 题名: 其他题名信息[M]. 其他责任者. 版本项. 出版地: 出版者, 出版年: 引文页码[引用日期]. 获取和访问路径. DOI.
```

- 第 1 版通常不著录版本项；
- 学位论文、报告、标准等在具体场景中使用 `[D]`、`[R]`、`[S]`；
- 专著作为引文参考文献时按实际需要著录引文页码；作为阅读型参考文献时可不著录引文页码。

### 5.2 专著中的析出文献 / 会议录中的论文

```text
析出文献主要责任者. 析出文献题名[C]//专著主要责任者. 专著题名: 其他题名信息. 版本项. 出版地: 出版者, 出版年: 析出文献页码[引用日期]. 获取和访问路径. DOI.
```

- `//` 后是会议录、论文集或专著自身的正式题录信息；
- 会议举办地不能自动充当出版地；
- 析出文献页码是其在载体文献中的正式页码或实际引文页码。

### 5.3 连续出版物整体

```text
主要责任者. 题名: 其他题名信息[J]. 起始年, 卷(期)-终止年, 卷(期). 出版地: 出版者, 起始出版年-终止出版年.
```

仍在出版时终止部分可留作开放区间，例如 `1984, 1(1)-.` 与 `1984-.`。

### 5.4 连续出版物中的析出文献 / 期刊论文

```text
主要责任者. 题名[J]. 期刊名, 年, 卷(期): 页码.
```

在线形式：

```text
主要责任者. 题名[J/OL]. 期刊名, 年, 卷(期): 页码[引用日期]. 获取和访问路径. DOI:10.xxxx/xxxx.
```

- 没有传统页码而正式采用文章编号时，如实保留文章编号，不伪造页码范围；
- 增刊示例结构可写为 `年, 卷(增刊2): 页码`；
- 合期在圆括号内按正式合期号著录，例如 `2001(9/10): 36-39`；
- 同一期刊连续刊载的后续部分可在原条目后继续列出后续年、卷、期、页码，以分号分隔，不必机械拆成多条。

### 5.5 报纸文章

```text
主要责任者. 题名[N]. 报纸名, YYYY-MM-DD(版次).
```

联机报纸使用 `[N/OL]`，并按实际情况著录引用日期、获取路径和 DOI。

### 5.6 学位论文

```text
主要责任者. 题名[D]. 所在地: 学位授予单位, 年: 引文页码.
```

在线形式用 `[D/OL]` 并著录引用日期、获取路径；存在 DOI 时如实著录。

### 5.7 报告

```text
主要责任者. 题名: 报告号[R]. 出版地: 出版者, 出版年: 引文页码.
```

报告号不存在时不补造；在线报告使用 `[R/OL]`。

### 5.8 标准

```text
主要责任者. 标准名称: 标准号[S]. 出版地: 出版者, 出版年: 引文页码.
```

标准发布日期、实施日期和出版年是不同字段，不得机械互换。

### 5.9 专利

```text
专利申请者或所有者. 专利题名: 专利号[P]. 公告日期或公开日期.
```

日期使用 `YYYY-MM-DD`。在线形式可使用 `[P/OL]` 并著录引用日期和获取路径。

### 5.10 独立电子资源、数据库、程序、数据集等

通用结构：

```text
主要责任者. 题名: 其他题名信息[类型/OL]. 版本项或其他必要信息. 出版地: 出版者, 出版年: 引文页码(更新或修改日期)[引用日期]. 获取和访问路径. DOI:10.xxxx/xxxx.
```

按资源真实属性替换类型代码：`EB`、`DB`、`CP`、`DS`、`A`、`CM`、`G`、`Z` 等。

对于纯在线资源，没有实际出版地、出版者等字段时，不得为了凑模板而补造；电子资源允许按标准规则省略不存在的出版地或出版者。

## 6. 出版项缺失的标准处理

### 6.1 出版地

- 非电子中文文献无出版地：著录 `[出版地不详]`；
- 非电子外文文献无出版地：著录 `[S.l.]`；
- 无出版地的电子资源可省略该项；
- 不得用会议举办地、作者单位所在地、学位申请者所在地或机构域名推断出版地。

### 6.2 出版者

- 非电子中文文献无出版者：著录 `[出版者不详]`；
- 非电子外文文献无出版者：著录 `[s.n.]`；
- 无出版者的电子资源可省略该项；
- 有多个出版者时，按标准取第一个或处于显要位置的出版者，不擅自拼接全部出版者。

### 6.3 出版年

出版年无法确定时，依次采用：

1. 版权年，例如 `c1988`；
2. 印刷年，例如 `1995印刷`；
3. 估计出版年，例如 `[1936]`。

估计年份必须置于方括号中。不得把网页抓取日期或搜索引擎日期直接当作出版年。

## 7. 在线资源与 DOI

- `/OL` 表示联机网络载体，不改变基本文献类型；
- 引用日期统一写为 `[YYYY-MM-DD]`；
- 更新或修改日期仅在正式来源明确给出时著录，形式为 `(YYYY-MM-DD)`；
- 获取和访问路径应指向实际资源、正式落地页或稳定访问地址；
- DOI 必须与该文献题名、作者、来源等题录相匹配；
- 当获取路径中已经完整包含 DOI 信息时，可避免机械重复；若路径不含 DOI 而正式来源给出 DOI，则按原文如实著录，推荐统一写作 `DOI:10.xxxx/xxxx`；
- 不根据题名相似度、搜索摘要或猜测补 DOI。

## 8. 页码、文章编号、引文页码

- 连续出版物析出文献的阅读型参考文献著录文章起讫页或起始页；
- 引文参考文献应著录实际引用信息所在页；
- 会议论文使用其在会议录或论文集中的正式页码；
- 专著作为引文文献时可著录实际引用页码；
- 文章编号不是页码，正式来源使用 article number 时保留其原形式；
- 数据库记录号、检索号、内部 ID 不得冒充页码。

## 9. 文字、版本与标点

- 题名原则上按正式信息源著录，不擅自改写专有名称；
- 必要时可采用双语著录，但应先著录信息资源原语种，再著录其他语种；
- 版本项按正式信息源著录，第 1 版通常省略；
- 日期按标准需要使用阿拉伯数字；
- 页码范围使用统一连接符；
- `et al.` 的拼写、作者大小写、标点和空格在同一参考文献表中保持一致；
- 标点问题属于格式层，不能误判为题录事实错误。

## 10. 事实核验原则

证据优先级：

1. 文献正式首页、题名页、版权页、正式 PDF；
2. 出版者、期刊、会议、大学、政府机构、标准组织正式页面；
3. DOI 正式落地页；
4. Crossref、PubMed、国家期刊平台、图书馆目录等权威题录服务；
5. 普通聚合页面仅作检索线索。

至少核对作者及顺序、题名、文献类型、来源名称、年卷期、页码或文章编号、出版项、编号字段、URL 和 DOI。正式来源冲突时，优先文献自身正式页面、题名页或版权页，并记录冲突及采用依据。

## 11. 最小回归检查

生成或审核结束前至少验证：

- `4+` 作者是否正确截断为前 3 名 + “等”/`et al.`；
- 无责任者在顺序编码制与著者-出版年制下是否分别处理；
- 非电子文献缺出版地/出版者是否使用标准缺省词；
- 出版年未知时是否按版权年→印刷年→估计年的顺序处理；
- 会议论文是否含 `//`；
- 在线期刊是否保持 `J` 而不是误写 `EB`；
- 连续出版物整体、合期、增刊和连续刊载能否识别；
- `DB/CP/DS/A/CM/G/Z` 是否按真实资源类型使用；
- 著者-出版年制是否正确排序并处理同著者同年 `a/b/c`；
- 正文顺序编码是否能识别 `[2,4,6-9]` 一类多文献标注；
- DOI、URL、页码、文章编号没有互相混淆；
- 格式结论与事实核验结论彼此独立。
