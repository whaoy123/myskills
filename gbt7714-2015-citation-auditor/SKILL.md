# GB/T 7714—2015 参考文献检查器

## 目标

对现有参考文献执行两类独立检查：

1. **格式合规检查**：依据 GB/T 7714—2015 判断结构、责任者、标点、文献类型、载体代码和著录项目。
2. **题录事实核验**：依据用户提供的 PDF 或正式网络来源核实作者、题名、年卷期、页码、文章编号、出版项、报告号、标准号、专利号、URL 和 DOI。

格式正确不等于题录事实已经核实。

开始前阅读：

- `references/gbt7714-2015-quick-reference.md`

## 输入

- 一条或多条现有参考文献；
- 论文参考文献章节或 Word/PDF 中的参考文献；
- 可选的论文 PDF、DOI、URL、学校或期刊模板；
- 用户指定的检查范围，例如“只看格式”“全部核实”“只修有问题的”。

## 检查模式

### 模式 A：格式检查

结论使用：

- `格式符合`
- `格式基本符合，但有一致性问题`
- `格式不符合`
- `仅凭条目无法判断`

### 模式 B：事实核验

结论使用：

- `题录已核实`
- `题录部分核实`
- `存在事实错误`
- `正式来源不足，无法核实`

默认同时执行 A 和 B。文献很多时，可先完成格式筛查，再优先核实高风险条目。

## 证据优先级

1. 文献正式首页、题名页、版权页或末页；
2. 出版者、期刊、会议、大学、政府机构、标准组织正式页面；
3. DOI 正式落地页；
4. Crossref、PubMed、国家期刊平台、图书馆目录等权威题录服务；
5. 普通聚合网站只能作线索。

同一字段冲突时，记录冲突来源和采用依据。

## 格式检查清单

### 1. 编号与引用体系

检查：

- 顺序编码是否连续；
- 是否存在重复编号、漏号、一条文献被拆成多条；
- 同一文献重复引用时编号是否保持一致；
- 是否把顺序编码制与著者-出版年制混用；
- 正文引用编号与文后参考文献是否需要进一步对应核查。

### 2. 主要责任者

检查：

- 不超过 3 人是否全部著录；
- 超过 3 人是否著录前 3 人后加“等”或 `et al.`；
- 个人著者是否采用姓在前、名在后的形式；
- 欧美著者名缩写后是否省略缩写点；
- 西文姓氏是否按本标准示例使用全大写形式；
- 汉语拼音姓名的姓是否全大写，名的缩写方式是否正确；
- 机构作者是否按正式机构名称著录；
- 作者数量与顺序是否需要正式题录核实。

### 3. 题名

检查：

- 题名是否缺失、截断或混入来源字段；
- 其他题名信息是否与正式题名一致；
- 原出版物中的拼写、大小写和专有名称是否被擅自修改；
- 题名后的文献类型和载体标识是否与资源实际属性一致。

### 4. 文献类型与载体代码

GB/T 7714—2015 常用类型：

- `M` 专著
- `C` 会议录
- `G` 汇编
- `N` 报纸
- `J` 期刊
- `D` 学位论文
- `R` 报告
- `S` 标准
- `P` 专利
- `DB` 数据库
- `CP` 计算机程序
- `EB` 电子公告
- `A` 档案
- `CM` 舆图
- `DS` 数据集
- `Z` 其他

电子载体：

- `MT` 磁带
- `DK` 磁盘
- `CD` 光盘
- `OL` 联机网络

重点检查：

- 期刊论文是否被误写为 `[EB/OL]`；
- 在线报告是否正确使用 `[R/OL]`；
- 在线学位论文是否正确使用 `[D/OL]`；
- 在线期刊是否正确使用 `[J/OL]`；
- 会议录中的论文是否按析出文献处理；
- 是否出现不属于本标准代码体系的类型或载体代码。

### 5. 专著

常用结构：

```text
主要责任者. 题名: 其他题名信息[M]. 其他责任者. 版本项. 出版地: 出版者, 出版年: 引文页码.
```

检查：

- 第 1 版是否被无必要著录；
- 出版地、出版者、出版年是否真实存在；
- 引文页码是否属于实际引用信息；
- 是否把作者单位所在地误作出版地。

### 6. 专著中的析出文献与会议论文

常用结构：

```text
析出文献主要责任者. 析出文献题名[C]//专著主要责任者. 专著题名. 出版地: 出版者, 出版年: 析出文献页码.
```

检查：

- `//` 是否存在且位置正确；
- `//` 后是否为会议录或论文集的正式题录信息；
- 出版地、出版者和出版年是否完整；
- 会议举办地是否被误作出版地；
- 作者单位或数据库平台是否被误作出版者；
- 页码是否为析出文献在会议录中的页码。

### 7. 期刊与报纸析出文献

期刊常用结构：

```text
主要责任者. 题名[J]. 期刊名, 年, 卷(期): 页码.
```

在线期刊：

```text
主要责任者. 题名[J/OL]. 期刊名, 年, 卷(期): 页码[引用日期]. 获取和访问路径. DOI.
```

报纸：

```text
主要责任者. 题名[N]. 报纸名, 出版日期(版次).
```

检查：

- 年、卷、期和页码顺序；
- 有卷号却漏卷号；
- 卷期颠倒；
- 文章编号是否被错误改写成页码范围；
- 在线形式是否具有引用日期和获取路径；
- DOI 是否与该文献匹配。

### 8. 学位论文

常用结构：

```text
主要责任者. 题名[D]. 所在地: 学位授予单位, 年: 引文页码.
```

检查：

- 学位授予单位所在地；
- 学位授予单位正式名称；
- 年份；
- 在线形式的 `/OL`、引用日期和获取路径；
- 是否把数据库所在地写成学位授予单位所在地。

### 9. 报告

常用结构：

```text
主要责任者. 题名: 报告号[R]. 出版地: 出版者, 出版年: 引文页码.
```

检查：

- 报告号是否真实存在；
- 发布机构、出版者和出版地是否有正式来源；
- 在线报告是否使用 `[R/OL]`；
- 是否仅因在线获取而误判为电子公告。

### 10. 标准

常用结构：

```text
主要责任者. 标准名称: 标准号[S]. 出版地: 出版者, 出版年: 引文页码.
```

检查：

- 标准号和标准名称是否匹配；
- 标准责任者、出版地、出版者和出版年是否有依据；
- 是否把发布日期、实施日期和出版年混为一项。

### 11. 专利

常用结构：

```text
专利申请者或所有者. 专利题名: 专利号[P]. 公告日期或公开日期.
```

检查：

- 专利申请者或所有者；
- 专利题名；
- 专利号；
- 公告或公开日期；
- 在线形式的引用日期与获取路径。

### 12. 独立电子资源

常用结构：

```text
主要责任者. 题名: 其他题名信息[EB/OL]. 出版地: 出版者, 出版年: 引文页码(更新或修改日期)[引用日期]. 获取和访问路径. DOI.
```

检查：

- 实际文献类型是否真属于独立电子资源；
- `/OL` 是否存在；
- 引用日期是否存在；
- 更新或修改日期是否有正式页面证据；
- URL 是否指向具体资源；
- 出版地、出版者、出版年不存在时是否被人为补造；
- DOI 是否真实匹配。

### 13. 标点、排版与字段边界

检查但区分严重程度：

- 责任者、题名、来源、出版项之间的标点；
- `[J]`、`[C]//`、`[R/OL]` 等位置；
- 中英文标点是否整体一致；
- `et al.` 拼写；
- 页码连接符和日期格式；
- 多余空格、句末标点等低风险问题。

低风险排版问题不得被描述为题录事实错误。

### 14. 重复与可疑字段

检查：

- 重复文献；
- 同一 DOI 对应不同题名；
- 年份、卷期和期刊出版历史明显冲突；
- 页码倒置；
- 文章编号被误写成页码；
- 数据库展示字段被抄入题录；
- 出版地、出版者或机构名称明显来自推断。

## 事实核验卡

每条文献建立：

```text
编号：
原条目：
文献类型：
正式证据：
作者：匹配 / 不匹配 / 未核实
题名：匹配 / 不匹配 / 未核实
来源名称：匹配 / 不匹配 / 未核实
年卷期：匹配 / 不匹配 / 未核实
页码或文章编号：匹配 / 不匹配 / 未核实
出版项：匹配 / 不匹配 / 未核实
报告/标准/专利编号：匹配 / 不匹配 / 未核实
URL：匹配 / 不匹配 / 不适用 / 未核实
DOI：匹配 / 不匹配 / 无 DOI / 未核实
格式结论：
事实结论：
建议修订：
置信度：高 / 中 / 低
```

## 问题等级

- **A 级：明确错误**
  - 作者、题名、年份、卷期、页码、文章编号、编号字段或 DOI 与正式来源不符；
  - 文献类型明显错误；
  - 使用了不属于本标准的类型或载体代码；
  - 缺少该文献结构中的关键著录项目。

- **B 级：高概率问题**
  - 正式来源之间冲突；
  - 出版地或出版者疑似推断；
  - 会议论文析出结构不完整；
  - 载体标识与在线获取信息矛盾。

- **C 级：一致性或低风险格式问题**
  - 空格、连接符、标点或大小写不统一；
  - 同一文献表在线信息处理策略不一致，但不影响识别。

- **D 级：无法核实**
  - 缺少原文；
  - 正式页面不可访问；
  - 权威题录只提供部分字段。

## 输出格式

默认：

| 编号 | 格式结论 | 事实核验 | 发现的问题 | 建议修改 | 置信度 |
|---|---|---|---|---|---|

随后给出“建议定稿版本”。

必须区分：

- `符合格式，但未完成事实核验`
- `格式和题录均已核实`
- `存在明确事实错误`
- `现有正式信息不足`

没有问题的条目可以合并说明；凡声称“题录已核实”，必须有正式证据。

## 禁止事项

- 不因条目看起来完整就声称题录真实；
- 不用普通搜索摘要替代正式来源；
- 不从作者单位、机构所在地、网页域名推断出版地或出版者；
- 不把网页下载方式当作文献类型；
- 不擅自修改原题名的正式拼写；
- 不用不属于 GB/T 7714—2015 的代码体系修订条目；
- 不忽略学校或期刊的特殊模板；模板存在额外规则时，应单独说明其约束。
