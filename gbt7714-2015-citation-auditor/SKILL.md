# GB/T 7714—2015 参考文献审核器

## 目标

对现有引用执行三个彼此独立但可联合输出的检查：

1. **格式合规检查**：结构、责任者、文献类型、载体、字段顺序、出版项、标点等是否符合 GB/T 7714—2015；
2. **题录事实核验**：作者、题名、来源、年卷期、页码、文章编号、出版项、编号字段、URL、DOI 是否与正式来源一致；
3. **正文-文后对应检查**：正文标注体系、编号/著者年份、重复引用、缺失引用、孤立条目和排序是否一致。

格式正确不等于题录事实已经核实；题录真实也不等于格式符合标准。

开始前阅读：

- `references/gbt7714-2015-quick-reference.md`

## 输入

- 一条或多条现有参考文献；
- 论文参考文献章节；
- Word/PDF 中正文 + 参考文献；
- 可选的论文 PDF、DOI、URL、学校或期刊模板；
- 用户指定的检查范围，例如“只看格式”“全部核实”“检查正文引用对应关系”“只修有问题的”。

## 默认检查模式

### 模式 A：格式检查

结论：

- `格式符合`
- `格式基本符合，但有一致性问题`
- `格式不符合`
- `仅凭条目无法判断`

### 模式 B：题录事实核验

结论：

- `题录已核实`
- `题录部分核实`
- `存在事实错误`
- `正式来源不足，无法核实`

### 模式 C：正文-文后对应检查

结论：

- `对应关系正确`
- `存在编号/著者年份不一致`
- `正文有引用但文后缺条目`
- `文后有条目但正文未引用`
- `引用体系混用`
- `正文范围不足，无法判断`

默认有正文时执行 A+B+C；只有参考文献表时执行 A+B。文献数量很多时可先完成格式筛查，再重点核实高风险条目，但不能把“尚未核实”写成“已核实”。

## 证据优先级

1. 文献正式首页、题名页、版权页或末页；
2. 出版者、期刊、会议、大学、政府机构、标准组织正式页面；
3. DOI 正式落地页；
4. Crossref、PubMed、国家期刊平台、图书馆目录等权威题录服务；
5. 普通聚合网站仅作线索。

同一字段冲突时，记录冲突来源与采用依据。搜索摘要或 AI 摘要不得作为唯一事实依据。

## 第一步：识别引用体系

先判断全文使用：

- 顺序编码制；或
- 著者-出版年制。

如果正文与文后使用不同体系，或两种体系无说明混用，直接标为高优先级格式问题。

### 顺序编码制应检查

- 正文编号是否按首次出现顺序连续编码；
- 同一文献再次引用是否沿用原编号；
- 同一处多篇文献是否使用类似 `[2,4,6-9]` 的结构；
- 连续序号是否正确压缩；
- 文后条目是否按正文编号顺序排列；
- 是否存在正文编号没有文后条目；
- 是否存在文后条目从未在正文出现；
- 多次引用同一文献时是否错误生成多个不同编号；
- 需要标引引文页码时，是否按标准在正文标注中处理，而不是把同一条文献重复列入文后。

### 著者-出版年制应检查

- 正文是否采用 `(著者, 年)` 的结构；
- 正文已经出现著者姓名时是否只标出版年；
- 中国多著者是否使用第一著者 + “等”；
- 欧美多著者是否使用第一著者姓 + `et al.`；
- 同一著者同一年多篇文献是否使用 `a`、`b`、`c`……；
- `2020a/2020b` 在正文与文后是否一一对应；
- 文后是否先按文种集中，再按著者字顺和出版年排列；中文是否采用一致的拼音字顺或笔画笔顺；
- 著者-出版年制文后是否错误保留顺序编码编号；
- 多次引用同一文献时著者和年份是否保持一致，并按需要在正文标注引文页码。

## 第二步：主要责任者检查

检查：

- 不超过 3 个责任者是否全部著录；
- 超过 3 个是否只著录前 3 个后加“等”或 `et al.`；
- 个人著者是否姓在前、名在后；
- 欧美著者名缩写后是否省略缩写点；
- 西文姓氏是否按本标准示例使用全大写形式；
- 汉语拼音姓名的姓是否全大写，名是否采用允许的全拼或首字母形式；
- 无责任者时：顺序编码制是否直接从题名开始或按来源合理著录；著者-出版年制是否使用“佚名”或相应词；
- 机关团体是否按正式信息源著录；西文机关团体上下级是否按层级处理；
- 作者人数、顺序和机构层级是否与正式题录一致。

## 第三步：题名检查

检查：

- 题名是否缺失或截断；
- 题名与来源名称是否串位；
- 其他题名信息是否有正式依据；
- 专有名称、符号和原文拼写是否被擅自改写；
- 必要的双语著录是否先原语种后其他语种；
- 题名后的类型/载体标识是否与实际资源匹配。

## 第四步：文献类型与载体检查

允许类型：

- `M` 普通图书/专著
- `C` 会议录
- `G` 汇编
- `N` 报纸
- `J` 期刊
- `D` 学位论文
- `R` 报告
- `S` 标准
- `P` 专利
- `DB` 数据库
- `CP` 计算机程序
- `EB` 电子公告
- `A` 档案
- `CM` 舆图
- `DS` 数据集
- `Z` 其他

电子载体：`MT`、`DK`、`CD`、`OL`。

重点抓：

- 期刊论文被误写成 `[EB/OL]`；
- 在线报告、学位论文、专利、数据集被统一写成 `EB`；
- `DB/CP/DS/A/CM/G` 被错误归为 `Z`；
- 非在线资源错误加 `/OL`；
- 在线资源缺少与基本类型匹配的 `/OL`；
- 使用了不属于本标准代码表的代码。

文献类型标识在 GB/T 7714—2015 中属于选择项目，因此“没有 `[J]`”不能在脱离用户模板时机械判为题录事实错误；但同一文献表的处理应一致，且本 skill 修订时默认保留类型标识。

## 第五步：按文献结构检查

### 5.1 普通图书 / 专著

常用结构：

```text
主要责任者. 题名: 其他题名信息[M]. 其他责任者. 版本项. 出版地: 出版者, 出版年: 引文页码.
```

检查：

- 第 1 版是否无必要著录；
- 版本项是否真实；
- 出版地、出版者、出版年是否完整或按标准缺省规则处理；
- 是否把作者单位所在地当出版地；
- 引文参考文献是否按实际需要著录引文页码；
- 阅读型专著是否被强行要求必须写引文页码。

### 5.2 专著中的析出文献 / 会议论文

常用结构：

```text
析出文献主要责任者. 析出文献题名[C]//专著主要责任者. 专著题名. 出版地: 出版者, 出版年: 析出文献页码.
```

检查：

- `//` 是否存在且位置正确；
- `//` 后是否为会议录、论文集或专著的正式题录；
- 会议举办地是否被误作出版地；
- 作者单位或数据库平台是否被误作出版者；
- 页码是否属于析出文献而不是会议总页数或数据库记录号。

### 5.3 连续出版物整体

常用结构：

```text
主要责任者. 题名[J]. 起始年, 卷(期)-终止年, 卷(期). 出版地: 出版者, 起始出版年-终止出版年.
```

检查：

- 是否把连续出版物整体误按单篇期刊论文著录；
- 起止年卷期是否与出版历史一致；
- 仍在出版时是否正确保留开放区间；
- 出版地、出版者、出版年范围是否合理。

### 5.4 期刊 / 连续出版物析出文献

常用结构：

```text
主要责任者. 题名[J]. 期刊名, 年, 卷(期): 页码.
```

在线形式：

```text
主要责任者. 题名[J/OL]. 期刊名, 年, 卷(期): 页码[引用日期]. 获取和访问路径. DOI:10.xxxx/xxxx.
```

检查：

- 年、卷、期、页码次序；
- 正式来源有卷号却漏卷号；
- 卷期颠倒；
- 文章编号被伪造成页码；
- 增刊标识是否被丢失或误写；
- 合期是否按类似 `(9/10)` 形式保留；
- 连续刊载是否被无理由拆成多个重复条目；
- 在线形式是否具有引用日期和获取路径；
- DOI 是否真实匹配。

### 5.5 报纸文章

```text
主要责任者. 题名[N]. 报纸名, YYYY-MM-DD(版次).
```

检查日期、版次；联机报纸再检查 `[N/OL]`、引用日期与路径。

### 5.6 学位论文

```text
主要责任者. 题名[D]. 所在地: 学位授予单位, 年: 引文页码.
```

检查：

- 学位授予单位所在地；
- 学位授予单位正式名称；
- 年份；
- 是否把数据库所在地写成学位授予单位所在地；
- 在线形式的 `[D/OL]`、引用日期、获取路径与 DOI。

### 5.7 报告

```text
主要责任者. 题名: 报告号[R]. 出版地: 出版者, 出版年: 引文页码.
```

检查报告号、发布机构、出版地、出版者和在线载体。不存在的报告号不得为凑格式补造。

### 5.8 标准

```text
主要责任者. 标准名称: 标准号[S]. 出版地: 出版者, 出版年: 引文页码.
```

检查标准号与名称是否匹配；发布日期、实施日期和出版年是否被混为一项。

### 5.9 专利

```text
专利申请者或所有者. 专利题名: 专利号[P]. 公告日期或公开日期.
```

检查申请者/所有者、题名、专利号、公告/公开日期；在线形式再检查引用日期和获取路径。

### 5.10 DB / CP / EB / DS / A / CM / G / Z

先检查资源真实属性，再检查其是否套用了正确的专著、析出文献或电子资源结构。

重点检查：

- 真实数据库是否为 `DB`；
- 软件/程序是否为 `CP`；
- 数据集是否为 `DS`；
- 档案是否为 `A`；
- 舆图是否为 `CM`；
- 汇编是否为 `G`；
- `EB` 是否仅用于独立电子公告/网页等合适场景；
- `Z` 是否仅用于确实无法归入已有类型的资源。

## 第六步：出版项缺失检查

这是强制边界检查，不得把“查不到”简单判为“留空正确”。

### 出版地

- 非电子中文文献无出版地：应为 `[出版地不详]`；
- 非电子外文文献无出版地：应为 `[S.l.]`；
- 无出版地电子资源可省略；
- 如果条目用机构所在地、会议举办地等推断出版地，标为事实风险。

### 出版者

- 非电子中文文献无出版者：应为 `[出版者不详]`；
- 非电子外文文献无出版者：应为 `[s.n.]`；
- 无出版者电子资源可省略；
- 多个出版者时检查是否按第一个或显要位置出版者处理。

### 出版年

出版年无法确定时，检查是否按：

1. 版权年 `cYYYY`；
2. 印刷年 `YYYY印刷`；
3. 估计年 `[YYYY]`。

如果直接使用网页上传日期、抓取日期或搜索引擎日期，应判为事实错误或高风险问题。

## 第七步：在线信息与 DOI 检查

检查：

- `/OL` 是否与基本类型正确组合；
- 引用日期是否为 `[YYYY-MM-DD]`；
- 更新或修改日期是否来自正式页面，而非网页抓取时间；
- URL 是否指向具体资源或正式落地页；
- 是否误用搜索结果 URL、临时会话 URL、跟踪链接；
- DOI 是否与作者、题名、来源、年份等匹配；
- 获取路径已经完整包含 DOI 时是否发生无意义重复；
- 路径不含 DOI 而正式来源有 DOI 时是否漏著录；
- 没有 DOI 的资源是否被人工猜出 DOI。

## 第八步：页码与文章编号检查

- 阅读型期刊或析出文献：应有文章起讫页或起始页；
- 引文参考文献：应核对实际引用信息所在页；
- 会议论文：页码必须属于会议录中的该论文；
- 文章编号必须保持文章编号身份；
- 数据库记录号、检索号、内部 ID 不得当页码；
- 页码倒置、异常范围或明显超出刊物范围列为高风险项。

## 第九步：标点、排版与字段边界

检查但区分严重程度：

- 责任者、题名、来源、出版项之间标点；
- `[J]`、`[C]//`、`[R/OL]` 等位置；
- 中英文标点和空格是否一致；
- `et al.` 拼写；
- 页码连接符和日期格式；
- 多余空格、句末标点；
- 著者-出版年制年份位置；
- 正文 `[2,4,6-9]` 一类压缩格式。

低风险排版问题只能归入格式层，不得描述为题录事实错误。

## 第十步：重复、冲突和可疑字段

检查：

- 完全重复文献；
- 同一 DOI 对应不同题名；
- 同一题名对应多个互相冲突 DOI；
- 年份、卷期与期刊出版历史冲突；
- 同一文献被分配多个编号；
- 同著者同年未区分 `a/b/c`；
- 页码倒置；
- 文章编号误写页码；
- 数据库展示字段被抄进参考文献；
- 出版地、出版者或机构名称明显来自推断。

## 事实核验卡

每条文献内部建立：

```text
编号/著者年键：
原条目：
引用体系：
文献类型：
正式证据：
作者：匹配 / 不匹配 / 未核实
题名：匹配 / 不匹配 / 未核实
来源名称：匹配 / 不匹配 / 未核实
年卷期：匹配 / 不匹配 / 未核实
页码或文章编号：匹配 / 不匹配 / 未核实
出版项：匹配 / 不匹配 / 未核实
报告/标准/专利编号：匹配 / 不匹配 / 未核实
日期：匹配 / 不匹配 / 未核实
URL：匹配 / 不匹配 / 不适用 / 未核实
DOI：匹配 / 不匹配 / 无 DOI / 未核实
正文对应：匹配 / 不匹配 / 无正文 / 未核实
格式结论：
事实结论：
建议修订：
置信度：高 / 中 / 低
```

## 问题等级

### A 级：明确错误

- 作者、题名、年份、卷期、页码、文章编号、编号字段或 DOI 与正式来源不符；
- 文献类型明显错误；
- 使用不属于本标准的类型或载体代码；
- 关键字段结构错误；
- 顺序编码编号与正文无法对应；
- 著者-出版年制 `a/b/c` 与正文不一致；
- 非电子文献明确缺出版地/出版者却既未查实也未使用标准缺省词。

### B 级：高概率问题

- 正式来源之间冲突；
- 出版地或出版者疑似推断；
- 会议论文析出结构不完整；
- 载体标识与在线信息矛盾；
- 卷期、页码或文章编号异常；
- 文后条目正文未引用，且用户要求审核引文参考文献。

### C 级：一致性或低风险格式问题

- 空格、连接符、标点、大小写不统一；
- 同一文献表类型标识或在线信息策略不统一，但不影响识别；
- 文献类型标识作为选择项的使用不一致。

### D 级：无法核实

- 缺少原文；
- 正式页面不可访问；
- 权威题录只提供部分字段；
- 正文范围不足，无法判断引用对应关系。

## 输出格式

默认：

| 编号/著者年键 | 格式结论 | 事实核验 | 正文对应 | 发现的问题 | 建议修改 | 等级 | 置信度 |
|---|---|---|---|---|---|---|---|

随后只列需要修改的最终条目：

```text
修订后：
[1] ...
```

如果用户提供整篇正文，再增加总览：

```text
正文引用数：
文后条目数：
缺失条目：
孤立条目：
重复编号：
体系混用：
```

用户只要求最终修订结果时，可以压缩过程，但不能把未核实字段伪装成已核实。

## 提交前质量门槛

- [ ] 使用的是 GB/T 7714—2015 规则；
- [ ] 已识别顺序编码制或著者-出版年制；
- [ ] 正文与文后使用同一引用体系；
- [ ] `4+` 作者、无责任者和机构作者均按规则检查；
