# source-to-understanding-md

把“要理解的技术文档”与“用户已经学过的教材/知识”结合起来，输出真正可读懂的 Markdown 学习说明。

核心特征：

- 先整体、后局部，优先使用原始文档截图；
- 公式必须代入真实参数并解释物理意义；
- 区分原文事实、从电路推导出的结果和教材知识；
- 用户每次修改说明后，更新其讲解偏好和已知知识；
- `learner/knowledge.yaml`、`learner/explanation-profile.md`、`learner/revision-log.md` 构成持续学习状态。

主定义见 [SKILL.md](SKILL.md)。
