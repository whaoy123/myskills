# Output Template

按当前电路需要选用，不要求机械填满。

```markdown
# <功能名>

![整体位置](images/01_whole.png)

<上一块与这一块的关系；本节功能一句话>

## 1. 这部分用到哪些输入
<只列当前功能相关输入；邻近支路一句带过>
<必要时先算正常输入/前级变换后的量级>

## 2. 先看完整电路
![完整电路](images/02_full_block.png)

功能上拆成 2~5 个子块。
已知原理一句带过，这次只展开新难点。

## 3. <当前最关键的“为什么”问题>
![局部](images/03_zoom.png)

<先具体支路/节点，再公式，再推广；必要时先理想化>

## 4. <为什么前面/旁边必须这样处理>
<没有它会发生什么 → 这个电路解决什么>

## 5. <关键 R/C/门槛/时序为什么这样>
<真实值 → 公式 → 数值 → 含义 → 太大/太小 → 反推限制>

## 6. 正常 <工况> 时，这个节点大概是多少
<把外部物理量一路算到内部节点，建立量级直觉>

## 7. 最后的 <输出级> 是干什么的
<送到哪里；隔离/缓冲/比较为什么需要>

## 8. 这部分在整个 <系统> 里到底干什么
<3~5 步因果链回到系统；不重复前文>

## 来源
- primary source
- textbook/reference if actually used
- derived calculations caveat
```

规则：
- 原图优先；不要生成替代图。
- 已学过机制一句复用。
- 公式和实测优先于修辞。
- 同一因果链只表达一次。
- caveat 只保留会改变工程判断的一层。
