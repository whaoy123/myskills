# GB/T 7714—2025 参考文献检查器

## 目标

对用户现有参考文献执行两类相互独立的检查：

1. **格式合规检查**：仅依据条目文字判断是否符合 GB/T 7714—2025 的结构、标点、类型标识和必备项目要求。
2. **题录事实核验**：使用用户提供的 PDF 或正式网络来源，确认作者、题名、年份、卷期、页码、文章编号、报告编号、出版地、出版者、URL 和 DOI 是否真实准确。

不得把“格式看起来正确”表述成“文献信息已经核实”。

开始前阅读：

- `references/gbt7714-2025-quick-reference.md`

## 输入

- 一条或多条现有参考文献；
- 文献列表、论文参考文献章节或 Word/PDF 中的参考文献；
- 可选的论文 PDF、DOI、URL 或学校格式模板；
- 用户指定的检查范围，例如“只看格式”“全部上网核实”“只查有问题的”。

## 检查模式

### 模式 A：格式检查

不联网也可执行。结论只能使用：

- `格式符合`
- `格式基本符合，但有一致性问题`
- `格式不符合`
- `仅凭条目无法判断`

### 模式 B：事实核验

需要逐条查找正式证据。结论可以使用：

- `题录已核实`
- `题录部分核实`
- `存在事实错误`
- `公开来源不足，无法核实`

默认同时执行 A 和 B；若文献很多，可先做格式筛查，再优先核实高风险条目。

## 证据优先级

1. 文献正式首页、题名页、版权页或末页；
2. 出版者、期刊、会议、大学、政府机构、标准组织正式页面；
3. DOI 正式落地页；
4. Crossref、PubMed、NASA NTRS、国家期刊平台等权威题录服务；
5. 图书馆目录或高质量学术数据库；
6. 普通聚合网站只能作为线索，不能单独支撑“已核实”。

同一字段出现冲突时，保留各来源差异并说明采用依据。

## 格式检查清单

### 1. 编号与列表完整性

检查：

- 编号是否连续；
- 是否存在 `[2.1]`、`[6.1]` 等交叉引用、脚注或批注残留；
- 是否有重复编号、漏号或一条文献被拆成两条；
- 正文引用编号和文后编号是否需要另行核对。

### 2. 主要责任者

检查：

- 不超过 3 人是否全部列出；
- 超过 3 人是否只列前 3 人后加“等”或 `et al.`；
- 中文、英文责任者表达是否混乱；
- 西文作者是否采用姓在前、名缩写在后；
- 作者顺序是否可能被数据库颠倒。

作者数量和顺序属于事实问题，必须结合原文或正式题录才能最终确认。

### 3. 题名

检查：

- 题名是否缺失、截断或混入副标题；
- 题名后文献类型标识是否紧随题名；
- 中文题名中不必要的中英文空格只记为排版一致性问题，不应夸大为题录事实错误；
- 原出版物题名中的特殊拼写、大小写或错误拼写，不应在无证据时擅自修正。

### 4. 文献类型与载体标识

检查是否误用：

- 期刊论文 `[J]` 或 `[J/OL]`；
- 会议录 `[C]`，会议论文通常使用 `[C]//`；
- 学位论文 `[D]`；
- 报告 `[R]`；
- 标准 `[S]`；
- 专利 `[P]`；
- 网页、网站 `[EB/OL]`；
- 数据集 `[DS]`；
- 预印本 `[PP]`。

高频错误：

- 把在线技术报告错误写成 `[EB/OL]`，而不是 `[R/OL]`；
- 把从网页下载的期刊论文一律写成 `[EB/OL]`；
- 把正式按期刊连续出版的会议文章机械写成 `[C]`；
- 在线载体漏写 `/OL`，但后面又附 URL。

### 5. 期刊论文必备结构

应重点检查：

```text
主要责任者. 题名[J]. 期刊名, 年, 卷(期): 页码或文章编号.
```

在线形式：

```text
主要责任者. 题名[J/OL]. 期刊名, 年, 卷(期): 页码或文章编号. 获取和访问路径. 永久标识符.
```

检查项：

- 年、卷、期是否顺序正确；
- 有卷号却漏写卷号；
- 把期号当卷号；
- 缺页码，或已有文章编号却误报为“缺页码”；
- 页码中混入数据库记录字段；
- 合期、增刊或文章编号格式是否完整；
- 同一期刊续接部分是否规范。

### 6. 会议论文必备结构

检查：

- 论文题名后是否为 `[C]//`；
- 是否写出会议录题名；
- 是否写出出版地、出版者、出版年和页码（有则著录）；
- 会议举办地、出版地和作者单位所在地是否被混淆；
- `IEEE`、`IOP Publishing` 等是否确实是该出版物的出版责任者，而非数据库平台名称。

### 7. 报告

检查：

- 是否使用 `[R]` 或 `[R/OL]`；
- 报告编号有则著录；
- 发布日期和引文页码有则著录；
- 在线报告是否有获取和访问路径；
- 出版地和出版者是否来自题名页，而不是根据机构所在地推断。

### 8. 学位论文

检查：

- `[D]` 或 `[D/OL]`；
- 学位授予单位所在地；
- 学位授予单位；
- 学位授予年；
- 引文页码有则著录；
- 在线文献的获取和访问路径。

### 9. 网站和网页

检查：

```text
主要责任者. 题名[EB/OL]. (创建或修改日期)[引用日期]. 获取和访问路径.
```

- 引用日期必须存在；
- 日期格式为 `YYYY-MM-DD`；
- 创建或修改日期未知时不要编造；
- 搜索引擎抓取日期不能替代网页日期；
- URL 应指向具体资源，避免会话链接或临时跳转链接。

### 10. DOI 与永久标识符

- DOI 对电子资源为可选项，不是所有条目强制必填；
- 某些条目有 DOI、某些没有，不自动判为错误；
- 但同一参考文献表的 DOI 策略应尽量一致；
- DOI 必须与该文献匹配；
- `https://doi.org/...` 与 `DOI: ...` 不应无意义重复；
- DOI 不能替代年、卷、期、页码或文章编号等已有必备题录字段。

### 11. 标点与排版

检查但区分严重程度：

- 责任者后、题名后、期刊名后、年份卷期和页码之间的标点；
- `[J]`、`[C]//`、`[R/OL]` 的位置；
- 中文全角和西文半角标点是否整体一致；
- `et al.` 是否拼写正确；
- 页码连接符统一；
- 多余空格、全角括号、句末缺句点等通常为低风险格式问题。

不要把一个无关紧要的空格描述成“正式题名错误”。

### 12. 重复与可疑字段

检查：

- 重复文献；
- 同一 DOI 对应多个题名；
- 年份早于会议或期刊创刊时间；
- 卷期与年份明显冲突；
- 页码倒置；
- 文章编号被误写成页码范围；
- 期刊官网与数据库字段不一致；
- `P.14-19,6` 等数据库展示字段被误抄入页码。

## 事实核验流程

对每条文献建立核验卡：

```text
编号：
原条目：
文献类型：
正式证据：
作者：匹配 / 不匹配 / 未核实
题名：匹配 / 不匹配 / 未核实
来源名称：匹配 / 不匹配 / 未核实
年卷期：匹配 / 不匹配 / 未核实
页码或文章编号：匹配 / 不匹配 / 未核实
出版项：匹配 / 不匹配 / 未核实
报告或标准编号：匹配 / 不匹配 / 未核实
DOI：匹配 / 不匹配 / 无 DOI / 未核实
格式结论：
事实结论：
建议修订：
置信度：高 / 中 / 低
```

## 问题等级

使用以下等级，避免所有问题同等处理：

- **A 级：明确错误**
  - 作者、题名、年份、卷期、页码、文章编号、报告编号或 DOI 与正式来源不符；
  - 文献类型明显错误；
  - 缺少该类型的必备字段。

- **B 级：高概率问题**
  - 正式来源之间存在冲突；
  - 出版地或出版者疑似推断；
  - 会议论文结构不完整；
  - 载体标识与 URL 表达矛盾。

- **C 级：一致性或低风险格式问题**
  - 多余空格；
  - 大小写、连接符或句末标点不统一；
  - DOI 策略不一致但不影响文献识别。

- **D 级：无法核实**
  - 缺少原文；
  - 正式网页不可访问；
  - 公开题录只显示部分字段。

## 输出格式

默认输出：

| 编号 | 格式结论 | 事实核验 | 发现的问题 | 建议修改 | 置信度 |
|---|---|---|---|---|---|

然后给出“建议定稿版本”。

必须明确区分：

- `符合格式，但未完成事实核验`
- `格式和题录均已核实`
- `存在明确事实错误`
- `现有公开信息不足`

对于没有问题的条目，可以合并说明，不必为每条重复冗长解释；但凡声称“题录正确”，必须有正式证据支持。

## 禁止事项

- 不因条目看起来完整就声称题录真实；
- 不用普通搜索摘要代替正式来源；
- 不把 DOI 当作缺失页码的通用替代品；
- 不推断出版地、出版者、会议地点或机构名称；
- 不把网页下载方式决定为文献类型；
- 不为了统一而擅自修改原题名的正式拼写；
- 不忽略用户学校或期刊的特殊模板；模板与国标不一致时，应并列说明。
