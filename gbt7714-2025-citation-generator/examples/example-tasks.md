# 示例任务

## 示例 1：从 DOI 生成

用户：

```text
按 GB/T 7714—2025 生成引用，DOI: 10.xxxx/xxxxx，不要 DOI 字段。
```

期望行为：

1. 打开 DOI 正式页面；
2. 核实作者、题名、期刊名、年、卷、期和页码或文章编号；
3. 默认输出 `[J]`；
4. 不添加 DOI；
5. 若正式页面与 PDF 冲突，列出冲突。

## 示例 2：从论文 PDF 生成

用户：

```text
根据这个 PDF 生成国标引用。
```

期望行为：

1. 查看论文首页和末页；
2. 提取作者、题名、期刊或会议录、年卷期、页码或文章编号、DOI；
3. 不能只使用 PDF 文件名；
4. 关键字段缺失时，说明缺失并询问是否联网核实。

## 示例 3：技术报告

用户：

```text
把这份 NASA 技术报告整理成 GB/T 7714—2025。
```

期望行为：

- 使用 `[R]` 或 `[R/OL]`；
- 保留正式报告编号；
- 出版地和发布机构必须来自题名页或机构正式记录；
- 不因为在线下载而改成 `[EB/OL]`。

## 示例 4：批量输出

用户：

```text
这些 DOI 和 PDF 全部生成参考文献，能查到 DOI 的统一保留。
```

期望行为：

- 使用 `all-available` DOI 策略；
- 输出参考文献、核验状态和待确认字段；
- 每条 DOI 必须核实匹配，不能仅根据题名搜索结果复制。
