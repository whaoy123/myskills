# GB/T 7714—2025 参考文献生成器

## 目标

根据用户提供的 DOI、URL、论文题名、题录信息或 PDF，生成符合 GB/T 7714—2025 的参考文献。输出必须可追溯，不得用猜测补齐作者、出版地、出版者、卷期、页码、文章编号、报告编号或 DOI。

开始前阅读：

- `references/gbt7714-2025-quick-reference.md`

## 接受的输入

- 一个或多个 DOI；
- 出版社、期刊、会议、机构或数据库页面 URL；
- 论文、报告、学位论文或标准 PDF；
- 用户粘贴的题名、作者、年份等不完整题录；
- 混合输入，例如“PDF + DOI + 学校模板要求”。

## 先确定用户策略

能从上下文确定时不要重复询问。无法确定且会实质影响结果时，最多询问一个问题。

需要确定的策略包括：

1. `输出范围`
   - 仅给最终参考文献；
   - 最终参考文献 + 核验说明；
   - 批量表格。

2. `DOI 策略`
   - `omit`：默认，不写 DOI；
   - `verified-only`：仅写已由正式来源核实的 DOI；
   - `all-available`：逐条查找并尽可能统一补充 DOI。

3. `载体策略`
   - `publication-first`：默认。已有稳定卷期页码或文章编号的期刊论文写 `[J]`，一般不附 URL；
   - `online-first`：用户明确要求保留在线获取信息时，写 `[J/OL]`、`[R/OL]` 等并附访问路径；
   - 网页、网站等本身即在线资源的文献始终按 `[EB/OL]` 等处理。

4. `编号策略`
   - 默认顺序编码制 `[1]`、`[2]`；
   - 用户已提供编号时保留原编号，除非用户要求重排。

## 工具与证据优先级

### 有 PDF 时

1. 先查看封面、题名页或论文第一页，不要只依赖 PDF 文件名或 PDF 元数据。
2. 查看页眉、页脚、版权页、文章首页和末页，提取：
   - 主要责任者；
   - 题名和其他题名信息；
   - 期刊或会议录题名；
   - 年、卷、期；
   - 起止页码或文章编号；
   - DOI、报告编号、标准编号；
   - 出版地、出版者、授予单位等。
3. PDF 为扫描件时，优先人工查看页面；只有无法读取时才做少量 OCR。
4. PDF 缺失关键字段且用户允许联网时，再用正式网页核实。

### 需要联网时

按以下优先级核验：

1. 出版者、期刊、会议、大学、政府机构、标准组织或 DOI 正式落地页；
2. 文献本身的正式 PDF；
3. Crossref、PubMed、NASA NTRS、国家期刊平台等权威题录服务；
4. 图书馆目录或高质量学术数据库；
5. 普通聚合网站仅用于发现线索，不作为唯一证据。

不要把搜索结果摘要、AI 摘要或二次转载当成正式题录来源。

## 执行流程

### 第一步：建立元数据记录

为每条文献建立内部记录：

```text
source_type:
carrier:
authors:
title:
other_title_info:
container_title:
year:
volume:
issue:
pages_or_article_number:
place:
publisher:
conference_name:
degree_institution_place:
degree_institution:
report_number:
standard_number:
patent_number:
published_or_updated_date:
cited_date:
url:
doi:
evidence:
unresolved_fields:
```

字段未知时保留为空，不得填入看似合理的内容。

### 第二步：判定文献类型与载体

使用标准的文献类型标识：

- 图书 `[M]`
- 期刊 `[J]`
- 报纸 `[N]`
- 会议录 `[C]`
- 学位论文 `[D]`
- 报告 `[R]`
- 标准 `[S]`
- 专利 `[P]`
- 网站、网页 `[EB]`
- 档案 `[A]`
- 地图 `[CM]`
- 数据集 `[DS]`
- 预印本 `[PP]`
- 汇编 `[G]`
- 计算机程序 `[CP]`
- 数据库 `[DB]`
- 其他 `[Z]`

电子资源载体常用：联机网络 `OL`，组合形式例如 `[J/OL]`、`[R/OL]`、`[EB/OL]`。

判定原则：

- 论文发表在期刊，即使从网页下载，也可按用户策略写 `[J]` 或 `[J/OL]`，不能误写为 `[EB/OL]`。
- 会议论文是会议录中的析出文献，使用 `[C]//` 或 `[C/OL]//`。
- 技术白皮书、NASA 技术备忘录、机构研究报告优先按 `[R]` 或 `[R/OL]`，不要因为在线获取就改为 `[EB/OL]`。
- Journal of Physics: Conference Series 等以期刊形式连续出版的会议论文，按正式出版物实际类型判定，不能仅因内容来自会议就机械写 `[C]`。
- 网页文章、机构页面、产品说明网页等才按 `[EB/OL]`。

### 第三步：规范主要责任者

- 责任者不超过 3 人：全部著录。
- 超过 3 人：著录前 3 人，中文后加“等”，英文后加 `et al.`。
- 中文姓名保留完整姓名。
- 西文姓名采用“姓在前、名缩写在后”，缩写一般不加点，例如 `Birrell A D`。
- 机构作者按正式机构名称著录。
- 不自行翻译或缩写机构名称，除非正式来源采用该形式。

### 第四步：按文献类型套用格式

#### 期刊析出文献

```text
[序号] 主要责任者. 析出文献题名[文献类型标识/文献载体标识]. 期刊名, 年, 卷(期): 页码或文章编号. 获取和访问路径. 永久标识符.
```

普通载体常用：

```text
[1] 作者. 题名[J]. 期刊名, 年, 卷(期): 页码.
```

无传统页码而有文章编号时，文章编号置于页码位置：

```text
[1] 作者. 题名[J]. 期刊名, 年, 卷(期): 012004.
```

#### 会议录中的析出文献

```text
[序号] 析出文献主要责任者. 析出文献题名[C]//会议录主要责任者. 会议录题名. 出版地: 出版者, 出版年: 页码.
```

会议录主要责任者、出版地或出版者确实未载明时，不得自行推断。根据正式来源和标准允许的缺项规则处理，并在核验说明中提示。

#### 图书

```text
[序号] 主要责任者. 题名[M]. 版本项. 出版地: 出版者, 出版年: 引文页码.
```

#### 学位论文

```text
[序号] 主要责任者. 题名[D]. 学位授予单位所在地: 学位授予单位, 学位授予年: 引文页码.
```

在线学位论文可使用 `[D/OL]` 并附获取和访问路径。

#### 报告

```text
[序号] 主要责任者. 题名: 报告编号[R]. 发布日期: 引文页码.
```

正式报告若明确给出出版地和发布机构，可按报告自身正式出版项完整著录。在线报告用 `[R/OL]`，附获取和访问路径。

#### 标准

```text
[序号] 标准编号 标准名称[S].
```

如标准正式题名页载有责任者、出版地、出版者和年份，可按标准相应项目完整著录。

#### 网站

```text
[序号] 主要责任者. 网站题名[EB/OL]. (创建或修改日期)[引用日期]. 获取和访问路径.
```

#### 网页

```text
[序号] 主要责任者. 网页题名[EB/OL]. (创建或修改日期)[引用日期]. 获取和访问路径.
```

- 创建或修改日期有则著录；
- 引用日期必备；
- 日期采用 `YYYY-MM-DD`；
- 不用搜索日期代替网页创建或修改日期。

### 第五步：处理 DOI 与 URL

- DOI 是永久标识符，对电子资源为可选项，不是每条文献必填。
- 默认不零散补 DOI；用户要求添加时，应使用统一策略。
- DOI 必须来自正式出版页面、文献 PDF 或权威元数据。
- URL 已使用 `https://doi.org/...` 时，不再重复写 `DOI:`。
- URL 与 DOI 同时存在时，避免重复表达同一入口；除非用户或单位模板明确要求两者都写。
- 不把数据库检索跳转链接、带会话参数的临时链接作为首选访问路径。

### 第六步：事实核验

至少交叉检查以下字段：

- 作者顺序和人数；
- 题名拼写；
- 年、卷、期；
- 页码或文章编号；
- 期刊名、会议录名；
- 报告编号、标准编号；
- DOI；
- 出版地和出版者是否明确载明。

若两个正式来源冲突：

1. 优先文献正式首页、题名页或版权页；
2. 其次出版者页面；
3. 列出冲突，不擅自合并；
4. 给出采用值和理由。

### 第七步：输出

单条文献默认输出：

```text
最终格式：
[1] ...

核验状态：已核实 / 部分核实 / 信息不足
待确认：无，或列出字段
```

批量文献默认输出表格：

| 编号 | 最终参考文献 | 核验状态 | 待确认字段 |
|---|---|---|---|

用户只要最终结果时，不输出冗长过程，但仍需在缺失字段处明确提示，不能静默猜测。

## 质量门槛

提交前逐项确认：

- 文献类型和载体标识正确；
- 主要责任者人数规则正确；
- 必备字段完整；
- 页码和文章编号没有混淆；
- 会议论文没有漏掉 `//` 后的会议录信息；
- 在线资源具有正确访问路径；
- 网页具有引用日期；
- DOI 策略在整批文献中一致；
- 没有从机构所在地、作者单位或网页域名推断出版地和出版者；
- 没有把搜索摘要中的错误元数据写入最终题录；
- 对无法核实的字段已明确标注。
