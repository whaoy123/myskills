# 自测报告：PCB 焊接清单/焊接表制作 Skill

## 测试输入

- 示例表：焊接表示例.xlsx
- 原理图/BOM PDF：Signal Pass-Through Test Board(1).pdf

## 按 Skill 独立执行后的应得输出结构

应生成 3 张表：

1. 焊接清单
2. 待确认
3. 来源说明

## 关键抽取结果

| 器件名称/型号 | 位号 | 数量 | 默认处理 |
|---|---|---:|---|
| DB78公 | J1, J2, J3, J4 | 4 | 连接器，按 78 个信号针/只计直插焊点，固定脚待确认 |
| 10mΩ 采样电阻 | R2, R5, R7, R8 | 4 | 贴片电阻，2 焊点/只 |
| 330mΩ 采样电阻 | R3 | 1 | 贴片电阻，2 焊点/只 |
| D3088-97 | U1, U2, U3, U4 | 4 | 跳线帽本体默认不计焊点，是否焊配套座待确认 |
| D3086-98 | U5 | 1 | 跳线帽本体默认不计焊点，是否焊配套座待确认 |
| testpoint | U11...U62，共 45 个 | 45 | 测试点默认 1 焊点/只，封装类型待确认 |

## 统计口径

- 器件总数：59
- 贴片焊点：10
- 直插焊点：375
- 总焊点：385

## 待确认项

1. DB78 固定脚/外壳脚是否也算焊点；
2. D3088-97 / D3086-98 是只插装跳线帽，还是需要焊接配套座；
3. testpoint 的具体封装是贴片还是直插；
4. 是否需要把大电流路径和采样电阻单独列焊接注意事项；
5. 是否需要增加“焊接完成勾选/验收签字”列。

## 结论

按该 Skill 可以复现当前任务的输出口径：能从原理图/BOM中整理器件型号、位号、数量和焊点统计，并生成焊接清单、待确认和来源说明三类内容。该 Skill 的规则没有绑定到 DB78 或本测试板，后续可复用于其他 PCB/转接板/测试板焊接清单制作。
