# Attribution

This work adapts workflow concepts from:

- Project: `Londeren/claude-plugins`, plugin `book-to-skill`
- Author/copyright holder: Sergey Lebedev
- Upstream license: MIT

Adapted concepts include source anchoring, independent extraction/validation passes, task-oriented reference organization, provenance tracking, and explicit self-checks.

This derivative changes the domain from extracting reusable methods from books to extracting traceable engineering requirements from component datasheets.
